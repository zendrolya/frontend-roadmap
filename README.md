# Frontend Roadmap

## Описание

Данный репозиторий содержит конспекты всей основной информации, касающейся Frontend-разработки, к которой можно периодически возвращаться и вспоминать забытое.

Репозиторий подойдет как абсолютным новичкам в этой сфере, так и опытным разработчикам.

Помимо теории, присутствуют практические задачи в качестве отдельных репозиториев по технологиям. Их можно выполнять и сверяться с решениями.
