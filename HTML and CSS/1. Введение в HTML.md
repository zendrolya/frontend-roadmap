# Введение в HTML

[🏠Содержание](../README.md) | [Вперед➡️](./2.%20Введение%20в%20CSS.md)

**HTML (HyperText Markup Language)** - язык для разметки гипертекста, набор правил, по которым браузер отличает элементы друг от друга.

> [!warning] Не является языком программирования потому, что HTML только размечает данные, но никак с ними не взаимодействует.

## Теги

**Теги (элементы)** - базовые блоки, из которых состоит HTML-разметка.

```html
<p>Простой текст</p>
```

Бывают двух видов - **непарные** и **парными**. Парные необходимо обязательно закрывать, как в примере выше.

Непарные теги выглядят следующим образом:

```html
<meta charset="utf-8" />
```

## Атрибуты

**Атрибуты** - дополнительная информация в тегах для браузера.

```html
<a href="https://google.com">Google Link</a>
```

В примере выше:

- `href` - атрибут
- `"https://google.com"` - значение атрибута

В данном примере атрибут `href` позволяет указать адрес ссылки (куда она ведет при клике).
