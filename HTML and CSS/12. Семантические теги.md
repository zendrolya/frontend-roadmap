# Семантические теги

## Header

Шапка - вводное содержимое, в котором могут быть заголовок, навигация, логотип, форма поиска и другие элементы.

```html
<header>
  <h1>Заголовок сайта</h1>
  <nav>
    <ul>
      <li>Раздел навигации 1</li>
      <li>Раздел навигации 2</li>
      <li>Раздел навигации 3</li>
    </ul>
  </nav>
</header>
```

## Main

Основное содержимое веб-страницы, наполнение в этом разделе всегда отличается от странице к странице.

```html
<main>
  <div>
    <h2>Заголовок статьи</h2>
    <p>Текст статьи...</p>
  </div>
</main>
```

## Footer

Подвал - как правило, содержит информацию об авторстве сайта, копирайте, дате создания и прочую служебную информацию.
Иногда могут присутствовать навигационные ссылки на страницы.

```html
<footer>
  <a href="#">Правила сайта</a>
  <p>Copyright © 2026 yoursite.com</p>
</footer>
```

## Address

Контактная информация автора или владельца документа/статьи.

Обычно содержит:

- Email
- Телефон
- Физический адрес
- Ссылки на соцсети

```html
<address>
  <a href="mailto:#">Иванов Иван</a>
</address>
```

## Article

Отдельный блок информации на странице, как правило, это какая-то статья или комментарии пользователей (в таком случае будет несколько вложенных `article` в основной `article`)

```html
<article>
  <h2>Статья про что-то</h2>
  <p>Описание этой статьи...</p>
</article>
```

> [!NOTE]
> Ключевая особенность `<article>` — он должен быть **самодостаточным**. Если вынести его на отдельную страницу или в RSS-ленту, смысл не потеряется.
>
> **Примеры:** пост в блоге, новость, отзыв пользователя, комментарий, карточка товара.

## Section

Группирует между собой общие элементы, например, новости, статьи, категории. Можно также разделить статью на несколько секций: шапка с информацией о статье, основное содержимое статьи, блок комментариев пользователей.

```html
<section>
  <h2>Заголовок статьи</h2>
  <p>Дата публикации: --.--.--</p>
</section>
<section>
  <p>Это основное содержимое статьи</p>
</section>
<section>
  <article>
    <h2>Комментарии</h2>
    <p>...</p>
  </article>
</section>
```

> [!NOTE]
> В отличие от `<div>`, `<section>` предназначен для **тематической группировки** контента. У секции **должен быть заголовок** (`<h2>`-`<h6>`), если он видимый или скрытый (для скринридеров).
>
> ```html
> <section>
>   <h2>Наши преимущества</h2>
>   <p>Преимущество 1</p>
>   <p>Преимущество 2</p>
> </section>
> ```

## Nav

Навигационное меню сайта

```html
<nav>
  <ul>
    <li><a href="#">Главная</a></li>
    <li><a href="#">О сайте</a></li>
    <li><a href="#">Раздел 1</a></li>
    <li><a href="#">Раздел 2</a></li>
    <li><a href="#">Раздел ...n</a></li>
  </ul>
</nav>
```

## Aside

Содержимое, которое **связано с основным контентом**, но не является его частью.

Часто используется для:

- Боковой панели (сайдбара)
- Дополнительной информации (сноски, цитаты)
- Рекламных блоков
- Виджетов соцсетей
- Блоков "Читайте также"

```html
<article>
  <h2>Как правильно ухаживать за кактусами</h2>
  <p>Основной текст статьи...</p>

  <aside>
    <h3>Совет</h3>
    <p>Поливайте кактус не чаще раза в месяц!</p>
  </aside>

  <p>Продолжение статьи...</p>
</article>
```

> [!NOTE]
> В отличие от `<section>`, содержимое `<aside>` не обязательно должно иметь заголовок, и оно не должно быть частью основного повествования.

## Figure и Figcaption

- `<figure>` - группирует медиаконтент (изображения, диаграммы, код) с подписью.
- `<figcaption>` - подпись к содержимому внутри `<figure>`.

```html
<figure>
  <img src="diagram.jpg" alt="Диаграмма продаж" />
  <figcaption>Диаграмма продаж за 2024 год</figcaption>
</figure>

<figure>
  <pre>
    <code>
      function hello() {
        console.log('Hello!');
      }
    </code>
  </pre>
  <figcaption>Пример функции на JavaScript</figcaption>
</figure>
```

`<figure>` может содержать не только изображения, но и таблицы, графики, блоки с кодом, цитаты - всё, что может быть вынесено с подписью.

## Hgroup

`<hgroup>` - группирует несколько связанных между собой заголовков для одного раздела (например, подзаголовок).

```html
<hgroup>
  <h2>Новый дизайн сайта</h2>
  <h3>Как мы переосмыслили пользовательский опыт</h3>
</hgroup>
```

## Time

`<time>` - обозначает время или дату в машиночитаемом формате.

```html
<article>
  <h2>Статья</h2>
  <p>
    Опубликовано:
    <time datetime="2024-06-15T14:30:00">15 июня 2024 в 14:30</time>
  </p>
</article>
```

## Details и Summary

- `<details></details>` - создает раскрывающийся блок (аккордеон).
- `<summary></summary>` - заголовок блока, по которому можно кликнуть для раскрытия.

```html
<details>
  <summary>Что такое семантическая верстка?</summary>
  <p>
    Семантическая верстка — это использование HTML-тегов в соответствии с их
    значением...
  </p>
</details>
```

## Семантика и доступность

Семантические теги **автоматически** сообщают скринридерам структуру страницы.

> [!NOTE]
> Семантические теги необходимо использовать всегда, где это возможно. Это улучшает SEO и делает сайт доступным для людей с ограниченными возможностями.
> div используется только для стилизации, а не для структуры.
