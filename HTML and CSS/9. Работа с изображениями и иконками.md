## Изображения

### Добавление

Основные форматы изображений для сайта:

- `png` - поддержка прозрачности
- `jpg/jpeg` - меньший вес по сравнению с `png` за счет сжатия с потерей качества
- `webp` - формат изображений от Google, разработанный специально для загрузки изображений на сайт
- `gif` - для гифок

Сервисы для сжатия изображений без потери качества:

- [tinypng](https://tinypng.com) - отлично сохраняет качество, максимум 20 изображений по 5 мб каждое
- [wertigo](https://wertigo.ru/compress/image) - позволяет настраивать сжатие
- [iloveimg](https://www.iloveimg.com/ru/compress-image) - быстрый, удобный, отлично сохраняет детали и сжимает размер

Стандартный и часто встречаемый вариант вставки изобржений - через тег `img`:

```html
<img src="" alt="" />
```

где:

- `src` - адрес изображения
- `alt` - alt-атрибут изображения (альтернативный текст)

Есть еще один способ вставки изображений, он используется, когда необходимо для разных устройств или вариантов отображения нужны разные картинки.

```html
<picture>
  <source srcset="" media="" type="" />
  <img src="" alt="" />
</picture>
```

где:

- `srcset` - адрес изображения
- `media` - медиа-выражение
- `type` - MIME-тип (image/webp, image/jpeg и т. д.)

То есть здесь есть два варианта адаптации:

1. Через `media` указываем, изображение какого формата показывать для, например, конкретной ширины экрана. Если формат не поддерживается, то будет показан стандартный тег `img`.
2. Браузер выбирает тот формат, который он поддерживает, если не указан `media`.

### Атрибут `loading`

Управляет загрузкой изображений для улучшения производительности:

- `eager` - загружать сразу (по умолчанию)
- `lazy` - отложенная загрузка (изображение загружается, когда попадает в область видимости)

Используем `loading: lazy`, когда изображение находится ниже первого экрана, это ускоряет загрузку веб-страницы.

### Атрибут `srcset`

Позволяет указать несколько версий изображения для разных разрешений экрана:

```html
<img
  src="photo-small.jpg"
  srcset="photo-small.jpg 480w, photo-medium.jpg 800w, photo-large.jpg 1200w"
  sizes="(max-width: 600px) 480px, (max-width: 1200px) 800px, 1200px"
  alt="Фото"
/>
```

- `srcset` - список изображений с указанием ширины (в w) или плотности пикселей (в x)
- `sizes` - указывает, какую ширину будет занимать изображение на разных экранах

### Стилизация

- Если у изображения не задана ширина и высота, то оно занимает пространство по своему размеру как есть.
- Изначально картинка является строчным элементом, но может иметь размеры

> [!NOTE]
> `<img>` — это **замещаемый (replaced) элемент**. Он является строчным (`display: inline`), но в отличие от обычных строчных элементов, ему можно задавать `width` и `height`, потому что браузер заменяет его на само изображение, размеры которого известны.

#### `object-fit: значение`

Определяет, как картинка или видео булут подстраиваться под заданные размеры.

- `fill` - значение по умолчанию для `object-fit`. Картинка растягивается, чтобы заполнить весь контейнер, **не сохраняя пропорции**. Из-за этого часто происходит деформация.
- `contain` - картинка поместится без нарушения пропорций, но могут остаться пустые места.
- `cover` - картинка заполнит всю доступную область не нарушая пропорций за счет обрезания краев.
- `none` - картинка не будет изменять свои размеры и поместится как есть.
- `scale-down` - сравнивает `none` и `contain` и выбирает тот вариант, который дает **меньший** размер изображения.

## Иконки

Существует несколько способов добавления иконок

### Иконочные шрифты

Использование готовых иконок в виде шрифта

```html
<head>
  <link
    rel="stylesheet"
    href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css"
  />
</head>
<body>
  <!-- Домик -->
  <i class="fas fa-home"></i>
  <!-- Пользователь -->
  <i class="fas fa-user"></i>
  <!-- Камера -->
  <i class="fas fa-camera"></i>
</body>
```

Плюсы:

- Простота использования
- Работают как текст (можно менять размер, цвет через CSS)
- Векторные - не теряют качество

Минусы:

- Тяжелый файл шрифта (даже если используется 1 иконка, загружаются все иконки сразу)
- Cложно кастомизировать

### SVG-иконки

Самый современный и производительный способ - использовать SVG. Для подключения SVG-иконки есть несколько способов.

1. Вставляем иконку прямо в HTML-документ:

```html
<svg
  width="24"
  height="24"
  viewBox="0 0 24 24"
  fill="none"
  xmlns="http://www.w3.org/2000/svg"
>
  <path d="M12 2L2 7L12 12L22 7L12 2Z" stroke="currentColor" stroke-width="2" />
  <path d="M2 17L12 22L22 17" stroke="currentColor" stroke-width="2" />
  <path d="M2 12L12 17L22 12" stroke="currentColor" stroke-width="2" />
</svg>
```

Плюсы:

- Максимальная производительность (не надо загружать файлы)
- Можно анимировать через CSS
- Легко менять цвет через `fill`/`stroke`

Минусы:

- Захламляет HTML-код
- Не кешируется

2. SVG-спрайт - объединяем все иконки в один файл и используем через `<use>`:

```html
<!-- Иконки хранятся в файле иконок icons.svg, каждая иконка имеет свой id -->
<svg xmlns="http://www.w3.org/2000/svg">
  <symbol id="icon-home" viewBox="0 0 24 24">
    <path d="M12 2L2 7L12 12L22 7L12 2Z" />
  </symbol>

  <symbol id="icon-user" viewBox="0 0 24 24">
    <path
      d="M12 12C14.21 12 16 10.21 16 8C16 5.79 14.21 4 12 4C9.79 4 8 5.79 8 8C8 10.21 9.79 12 12 12Z"
    />
  </symbol>
</svg>

<!-- В HTML-документе используется укороченная запись -->
<svg>
  <use href="icons.svg#icon-home" />
</svg>
```

Плюсы:

- Легко менять цвет
- Отдельный файл не захламляет HTML-документ

Минусы:

- Необходимо собирать сам спрайт и обновлять его при добавлении новых иконок

Сервисы для создания спрайтов:

- https://rechecker.ru/services/sprite
- https://svgsprit.es

3. Отдельный SVG-файл

Создаем папку с SVG-иконками и подключаем их через тег `img`:

```html
<img src="icons/home.svg" alt="Дом" class="icon" />
```

Плюсы:

- Кэширование и простота использования

Минусы:

- Нельзя менять цвет
