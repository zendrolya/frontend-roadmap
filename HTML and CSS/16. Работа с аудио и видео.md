## Видео

Тег `<video></video>` позволяет вставить видео на HTML-страницу.

### Атрибуты

Управление воспроизведением:

- `controls` - добавление стандартных элементов управления плеером.
- `autoplay` - автовоспроизведение видео после загрузки страницы.
- `loop` - зацикливание видео.
- `muted` - видео будет проигрываться без звука, пока пользователь сам его не включит.
- `playsinline` - указывает браузеру, что видео должно воспроизводиться **внутри страницы**, а не открываться в отдельном полноэкранном плеере.

Размеры:

- `width` - ширина плеера в пикселях
- `height` - высота плеера в пикселях
- `poster` - URL-адрес превью видео

Обработка данных:

- `buffered` - информация о загруженных минутах видео
- `preload` - управление предварительной загрузкой видео:
  - `none` - не загружать.
  - `metadata` - загрузка только служебной информации о видео: обложка, длительность, размер и т. д.
  - `auto` - загрузка видео вместе со страницей.

### Источник видео

Можно указать несколько источников, чтобы для пользователя загрузился вариант, поддерживаемый браузером:

```HTML
<video controls>
  <source src="путь до видео/*.webm" type="video/webm" />
  <source src="путь до видео/*.mp4" type="video/mp4" />
  <p>Браузер не поддеживает встроенные видео, скачайте его по <a href="путь до видео/*.mp4">ссылке</a></p>
</video>
```

В самом конце лучше указывать вариант загрузки видео на случай, если браузер вообще не поддерживает встроенные видео.

## Аудио

Тег `<audio></audio>` позволяет вставить аудио на HTML-страницу.

### Атрибуты

Управление воспроизведением:

- `controls` - добавление стандартных элементов управления аудиоплеером.
- `autoplay` - автовоспроизведение аудио после загрузки страницы.

- `muted` - аудио будет проигрываться без звука, пока пользователь сам его не включит.

Обработка данных:

  - `metadata` - загрузка только служебной информации об аудио: обложка, длительность, размер и т. д.

## Про форматы

### Видео-форматы

| Формат   | Кодек       | Поддержка | Когда использовать              |
| -------- | ----------- | --------- | ------------------------------- |
| **MP4**  | H.264 + AAC | Отличная  | Основной формат, работает везде |
| **WebM** | VP9 + Opus  | Хорошая   | Легче MP4, современный формат   |
| **AV1**  | AV1         | Средняя   | Самый новый, лучшее сжатие      |

### Аудио-форматы

| Формат  | Поддержка | Когда использовать                      |
| ------- | --------- | --------------------------------------- |
| **MP3** | Отличная  | Основной формат, работает везде         |
| **AAC** | Отличная  | Лучше MP3, используется в MP4           |
| **WAV** | Отличная  | Без сжатия, для профессионального аудио |
| **OGG** | Хорошая   | Открытый формат, легче MP3              |

## Субтитры

Тег `<track></track>` позволяет добавить субтитры и разделы для видео.

### Атрибуты

- `src` - путь к файлу субтитров (формат WebVTT или TTML)
- `kind` - тип трека:
  - `subtitles` - субтитры
  - `captions` - подписи (с описанием звуков для глухих)
  - `descriptions` - текстовое описание видео
  - `chapters` - разделы для навигации
  - `metadata` - служебная информация
- `srclang` - язык трека (код языка)
- `label` - название трека для пользователя
- `default` - включить этот трек по умолчанию

```HTML
<video controls>
  <source src="video.mp4" type="video/mp4" />
  <track
    src="subtitles-ru.vtt"
    kind="subtitles"
    srclang="ru"
    label="Русские субтитры"
    default
  />
  <track
    src="subtitles-en.vtt"
    kind="subtitles"
    srclang="en"
    label="English subtitles"
  />
</video>
```
