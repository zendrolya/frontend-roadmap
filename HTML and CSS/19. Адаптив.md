## Метатег Viewport

```html
<meta name="viewport" content="параметры_метатега" />
```

Параметры метатега:

- `width` - ширина области viewport в пикселях или `device-width`.
- `height` - высота области viewport в пикселях или `device-height`.
- `initial-scale` - коэффициент масштабирования начального размера `viewport` (число с плавающей точкой от `0.1`).
- `user-scalable` - разрешить или нет масштабирование при помощи жестов (`yes`/`no`).
- `minimum-scale` - минимальный масштаб размера viewport (число с плавающей точкой от `0.1`).
- `maximum-scale` - максимальный масштаб размера viewport (число с плавающей точкой от `0.1`).

Как правило, самый популярный вариант:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Изменять область viewport по ширине экрана, начальный масштаб страницы при загрузке (без увеличения или уменьшения).

## Импорт стилей

Директива `@import` позволяет покдлючать несколько CSS-файлов в один в зависимости от типа устройства, БЭМ-принципов и других условий.

```css
@import url(путь_до_файла_стилей);
```

## Медиа-запросы

### `@media`

```css
@media (функция: значение) {
}
```

Функции CSS Media Query:

- `aspect-ratio` - отношение ширины к высоте области отображения (браузера).
- `device-aspect-ratio` - отношение ширины к высоте экрана устройства.
- `max-width` / `min-width` и `max-height` / `min-height` - максимальная/минимальная ширина и высота области отображения (браузера).
- `max-device-width` / `min-device-width` и `max-device-height` / `min-device-height` - максимальная/минимальная ширина и высота экрана мобильного устройства.
- `orientation` - `portrait` (портретная) или `landscape` (альбомная) ориентация.
