# CSS переменные

[⬅️Назад](./) | [🏠Содержание](../README.md) | [Вперед➡️](./)

**CSS переменные (или официальное название - custom properties)** - свойства, которые могут хранить стандартные значения, которые можно присвоить обычным CSS свойствам. Эти значения можно многократно использовать в различных частях таблиц стилей.

## Создание и использование

Создание:

```CSS
:root {
  --red-color: #dc143c;
}
```

Правила именования CSS переменных:

- Регистр имеет значение (--color и --Color - разные переменные)
- В названии могут присутствовать буквы, цифры, дефисы и подчеркивания

> [!TIP]
> Объявление CSS переменных в `root` позволяет использовать их глобально для всех элементов.

CSS переменные наследуются и имеют область видимости, это значит, что их значения можно переопределять:

```CSS
/* Глобальная переменная */
:root {
  --color: red;
}

/* Переопределяем для .container и всех его потомков */
.container {
  --color: blue;
}

/* Переопределяем только для .special */
.special {
  --color: green;
}

/* Зависит от контекста */
.text {
  color: var(--color);
}
```

```html
<div class="container">
  <p class="text">Я синий (наследуется от .container)</p>
  <p class="text special">Я зеленый (переопределен в .special)</p>
</div>
<p class="text">Я красный (глобальная переменная)</p>
```

Использование:

```CSS
.some-block {
  background-color: var(--red-color);
}
```

### Использование нескольких переменных

В `var(--переменная, резервное_значение)` резервное значение используется **только если переменная не определена**:

```CSS
:root {
  --reserved-color: #5352ed;
}

/* --text-color не существует, поэтому будет использовано резервное значение  */
.some-div {
  color: var(--text-color, --reserved-color);
}

/* Можно вложенно указывать резервное значение для каждой переменной */
.another-div {
  color: var(--text-color, var(--reserved-color, red));
}
```

## Использование в создании тем

CSS переменные удобно использовать в темах web-приложения.

Простой пример, в котором в зависимости от значения атрибута `theme` в теге `html` меняется тема сайта:

```CSS
/* Стандартная светлая тема */
:root {
  --panel-bg-color: #dfe4ea;
  --container-bg-color: #f1f2f6;
  --text-color: #2f3542;
}

/* Темная тема (переопределяем значения CSS переменных) */
:root[theme="dark"] {
  --panel-bg-color: #2f3542;
  --container-bg-color: #57606f;
  --text-color: #ced6e0;
}
```

## Использование в адаптивности

Можно задать не только цвета, но и размеры, отступы и прочее, благодаря этому, используя CSS переменные в медиа-запросах, можно менять эти свойства в зависимости от разрешения экрана.

```CSS
/* Базовые размеры и отступы */
:root {
  --font-size-base: 16px;
  --padding-base: 20px;
}

/* Медиа-запросы, переопределяющие значения переменных */
@media (max-width: 768px) {
  :root {
    --font-size-base: 14px;
    --padding-base: 12px;
  }
}

@media (max-width: 480px) {
  :root {
    --font-size-base: 12px;
    --padding-base: 8px;
  }
}

/* В свойства текста будут подставляться значения в зависимости от разрешения экрана */
.text {
  font-size: var(--font-size-base);
  padding: var(--padding-base);
}
```
