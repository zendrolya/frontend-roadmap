l# Методология БЭМ

[⬅️Назад](./14.%20Grid.md) | [🏠Содержание](../README.md) | [Вперед➡️](./)

**БЭМ (Блок, Элемент, Модификатор)** - компонентный подход к веб-разработке. В его основе лежит принцип разделения интерфейса на независимые блоки. Он позволяет легко и быстро разрабатывать интерфейсы любой сложности и повторно использовать существующий код, избегая «Copy-Paste».

Официальный сайт: https://bem.info

## Блок

**Блок** - функционально независимый элемент страницы, который может быть переиспользован.

- Название блока должно отражать его смысл: `menu`, `button`, `header` и т. д.
- Блок не должен влиять на свое окружение: позиционирование (`position`), внешние отступы (`margin`) и границы (`outline`, `border` без `box-sizing: border-box;`), `float` не должны быть применены к блоку. За счет этого достигается возможность переиспользования блоков.
- Селекторы по тегам и `id` не рекомендуются к использованию в CSS.
- Блоки можно вкладывать друг в друга, допустима любая вложенность.

```html
<header class="header">
  <div class="header-menu">...</div>
</header>
```

## Элемент

**Элемент** - часть блока, которая не может использоваться без него.

- Название элемента характеризует его смысл: `item`, `text`, `link`
- К названию элемента приписывается его принадлженость к блоку через двойное подчеркивание:

```html
<header class="header">
  <div class="header-menu">
    <h2 class="header-menu__title">Заголовок меню</h2>
  </div>
</header>
```

- Элементы, как и блоки, можно точно так же вкладывать друг в друга с любой допустимой вложенностью. Вложенный элемент либо будет иметь только приписку принадлежности к блоку, либо будет иметь следующий вид:

```html
<header class="header">
  <div class="header-menu">
    <h2 class="header-menu__title">Заголовок меню</h2>
    <ul class="header-menu__list">
      <!-- Прописана принадлежность к определенному элементу -->
      <li class="header-menu__list-element">Элемент 1</li>
      <!-- Либо у элемента прописан только его блок -->
      <li class="header-menu__element">Элемент 2</li>
    </ul>
  </div>
</header>
```

Отличие блока от элемента:

- Блок - переиспользуемый и независимый от других компонентов фрагмент страницы.
- Если фрагмент не может использоваться независимо от какого-то другого, то это элемент.

## Модификатор

**Модификатор** - сущность для определения внешнего вида, состояния или поведения блока/элемента.

- Название характеризует внешний вид: `size_s` (размер), `red` (цвет), `theme_dark` (принадлежность к теме), `disabled` (состояние), `button_left-top` (поведение при взаимодействии с пользователем).
- Название модификатора отделяется от остальной части символом одиночного нижнего подчеркивания.

```html
<header class="header">
  <div class="header-menu">
    <h2 class="header-menu__title">Заголовок меню</h2>
    <ul class="header-menu__list">
      <li class="header-menu__list-element_disabled">Элемент 1 (отключен)</li>
      <li class="header-menu__list-element">Элемент 2</li>
    </ul>
  </div>
</header>
```

### Типы модификаторов

#### Булевый

- Отключен блок/элемент или нет (`disabled`)
- Находится ли блок/элемент в фокусе (`focused`)

#### Ключ-значение

- Используется, когда важно значение модификатора (`theme_dark`, `size_m` и т. д.)
- Допустимые варианты структуры таких модификаторов:
  - `имя-блока_имя-модификатора_значение-модификатора`
  - `имя-блока__имя-элемента_имя-модификатора_значение-модификатора`

## Файловая структура БЭМ-проекта

- Одна директория для одного блока, название директории и блока совпадают.
- Директория блока корневая для соответствующих ему элементов и модификаторов.
- Директории для элементов начинаются с двойного подчеркивания (`__`).
- Директории для модификаторов начинаются с одного подчеркивания (`_`).
- Скрипты и стили для блоков/элементов/модификаторов разделяются на файлы `.js` и `.css` соответственно.
