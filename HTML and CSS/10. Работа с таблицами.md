# Работа с таблицами

[⬅️Назад](./9.%20Работа%20с%20изображениями%20и%20иконками.md) | [🏠Содержание](../README.md) | [Вперед➡️](./11.%20Работа%20с%20формами.md)

Исторически первым принципом верстки веб-страниц был табличный.
В современной веб-разработке таблицы используются только для отображения табличных данных - информации, которая логически является таблицей (прайс-листы, расписания, статистика, сравнительные характеристики и т.д.).

## Создание

```html
<!-- Тег таблицы -->
<table>
  <!-- Table Row - строка таблицы -->
  <tr>
    <!-- Table Data - данные для конкретной строки через разделитель -->
    <td>Фрукт</td>
    <td>Глюкоза</td>
    <td>Фруктоза</td>
  </tr>
  <tr>
    <td>Абрикос</td>
    <td>0.1-3.4</td>
    <td>0.1-3.0</td>
  </tr>
  <tr>
    <td>Айва</td>
    <td>1.9-2.4</td>
    <td>5.6-6.0</td>
  </tr>
</table>
```

Результат:

<table>
  <tr>
    <td>Фрукт</td>
    <td>Глюкоза</td>
    <td>Фруктоза</td>
  </tr>
  <tr>
    <td>Абрикос</td>
    <td>0.1-3.4</td>

  </tr>
  <tr>
    <td>Айва</td>
    <td>1.9-2.4</td>

## Другие табличные теги

- `<th></th>` - ячейка-заголовок
- `<caption></caption>` - название таблицы (описывает, что указано в таблице)
- `<thead></thead>` - шапка таблицы
- `<tbody></tbody>` - тело таблицы
- `<tfoot></tfoot>` - футер таблицы (необходим для подведения итогов в таблице, например, при рассчете итоговой стоимости)

Обновленная таблица с учетом семантических тегов:

```html
<table>
  <caption>
    Содержание сахаров во фруктах (г на 100 г)
  </caption>
  <thead>
    <tr>
      <th>Фрукт</th>
      <th>Глюкоза</th>
      <th>Фруктоза</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Абрикос</td>
      <td>0.1-3.4</td>
      <td>0.1-3.0</td>
    </tr>
    <tr>
      <td>Айва</td>
      <td>1.9-2.4</td>
      <td>5.6-6.0</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">* Данные приведены для свежих фруктов</td>
    </tr>
  </tfoot>
</table>
```

Результат:

    Содержание сахаров во фруктах (г на 100 г)
  </caption>
  <thead>
    <tr>
      <th>Фрукт</th>
      <th>Глюкоза</th>
      <th>Фруктоза</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Абрикос</td>

### Атрибуты `td`

- `colspan` - количество столбцов, которое должна занять ячейка
- `rowspan` - количество строк, которое должна занять ячейка

> [!WARNING]
> При использовании colspan/rowspan важно следить, чтобы количество ячеек в строке/столбце соответствовало объединениям. Если ошибиться, то таблица сломается.

## Стилизация

### `border-collapse: значение`

Отображение границ таблицы

- `separate` - по умолчанию, соседние границы отображаются отдельно друг от друга (из-за этого получаем жирную полосу на пересечении границ).
- `collapse` - соседние границы отображаются как одна граница.

### `border-spacing: значение`

Расстояние между ячейками, работает только при `border-collapse: separate`.

- `Значение в любых единицах измерения` - размер отступа между границами

### `empty-cells: значение`

Указывает, как работать с пустыми ячейками.

- `show` - по умолчанию, показывать пустые ячейки.
- `hide` - граница и фон пустых ячеек не отображается, если вся строка состоит из пустых ячеек, то она прячется целиком.
