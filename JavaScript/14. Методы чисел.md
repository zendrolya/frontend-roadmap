## Способы записи числа

```js
const million = 1000000; // стандартная запись
const millionWithDash = 1_000_000; // с использованием разделителя для читаемости
const millionWithE = 1e6; // в прямом смысле 1 и 6 нулей
const small = 1e-6; // 0.000001
```

## Проблема точности

```js
0.1 + 0.2 === 0.3; // false
console.log(0.1 + 0.2); // 0.30000000000000004
```

> [!WARNING]
> Числа с плавающей точкой хранятся в формате IEEE 754, что приводит к ошибкам округления.

Правильное сравнение чисел с плавающей точкой:

```js
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON; // true
```

## Методы

### Преобразование в строку

```js
(255).toString(); // "255" - по умолчанию 10-тичная
(255).toString(2); // "11111111" - двоичная
(255).toString(16); // "ff" - шестнадцатеричная
(255).toString(73); // "73" - максимальная
```

### Округление

```js
Math.floor(2.9); // 2 - в меньшую сторону

Math.ceil(2.1); // 3 - в большую сторону

Math.round(2.5); // 3 - до ближайшего целого
Math.round(-2.5); // -2 - при .5 всегда в сторону +∞

Math.trunc(2.9); // 2 - отбрасывает дробную часть
Math.trunc(-2.9); // -2
```

### Форматирование

```js
(1.2345).toFixed(2); // "1.23"
console.log(typeof (1.2345).toFixed(2)); // "string" - toFixed всегда возвращает строку
```

### Парсинг строк в числа

```js
parseInt("123abc"); // 123 - парсит до первого не-числа
parseInt("123abc", 10); // 123 - парсинг до первого не-числа с указанием системы счисления
parseInt("ff", 16); // 255
parseInt("0x10"); // 16 - опредеяет hex автоматически

parseFloat("3.14abc"); // 3.14
parseFloat("3.14"); // 3.14
parseFloat(".5"); // 0.5
```

### Проверка чисел

```js
// Глобальный isFinite - преобразует аргумент к числу
isFinite("123"); // true
isFinite("abc"); // false
isFinite(null); // true

// Number.isFinite - НЕ преобразует
Number.isFinite("123"); // false
Number.isFinite(123); // true

// Глобальный isNaN - преобразует аргумент к числу
isNaN("abc"); // true
isNaN("123"); // false
isNaN(""); // false
isNaN(undefined); // true

// Number.isNaN - НЕ преобразует
Number.isNaN("abc"); // false
Number.isNaN(NaN); // true
Number.isNaN("123"); // false

Number.isInteger(5); // true
Number.isInteger(5.5); // false
Number.isInteger("5"); // false

Number.isSafeInteger(2 ** 53 - 1); // true
Number.isSafeInteger(2 ** 53); // false - превышает безопасный диапазон
```

### Math-методы

```js
Math.abs(-5); // 5 - модуль
Math.max(1, 2, 3); // 3 - максимум
Math.min(1, 2, 3); // 1 - минимум
Math.pow(2, 10); // 1024 - степень
Math.sqrt(16); // 4 - квадратный корень
Math.cbrt(27); // 3 - кубический корень
Math.sign(-5); // -1 - знак числа
Math.random(); // [0, 1) - случайное число
```

### Случайное целое число в диапазоне

```js
// От min до max включительно
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

getRandomInt(1, 10); // [1, 10]
```

### Константы Number

```js
Number.MAX_SAFE_INTEGER; // 9007199254740991 (2^53 - 1)
Number.MIN_SAFE_INTEGER; // -9007199254740991
Number.MAX_VALUE; // 1.7976931348623157e+308
Number.MIN_VALUE; // 5e-324
Number.EPSILON; // 2.220446049250313e-16
Number.POSITIVE_INFINITY; // Infinity
Number.NEGATIVE_INFINITY; // -Infinity
Number.NaN; // NaN
```
