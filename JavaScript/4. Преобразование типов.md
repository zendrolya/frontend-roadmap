# Преобразование типов

[⬅️Назад](./3.%20Типы%20данных.md) | [🏠Содержание](../README.md) | [Вперед➡️](./)

## Строковое

```js
let num = 5;
console.log(typeof num); // "number"
num = String(num);
console.log(typeof num); // "string"
```

Если сложить строку с чем-либо, всегда получается строка:

```js
"5" + 5; // "55"
"5" + true; // "5true"
"5" + null; // "5null"
"5" + undefined; // "5undefined"
"5" + {}; // "5[object Object]"
"5" + []; // "5"
"5" + [1, 2, 3]; // "51,2,3"
```

## Численное

> [!TIP]
> **Операнд (аргумент)** - то, к чему применяется оператор.
> **Унарный оператор** - оператор, который применяется к одному операнду.
> **Бинарный оператор** - оператор, который применяется к двум операндам.

Любой бинарный математический оператор, кроме `+` пытается преобразовать строку в число:

```js
console.log(2 + "2"); // "22"
console.log(2 - "2"); // 0
console.log(2 / "2"); // 1
console.log(2 * "2"); // 4
```

Унарный `-` и `+` пытаются преобразовать строку в число:

```js
console.log(+"2"); // 2
console.log(-"2"); // -2
console.log(+"2z"); // NaN
```

Запомнить:

```js
console.log(Number(undefined)); // NaN
console.log(Number(null)); // 0
console.log(Number(true)); // 1
console.log(Number(false)); // 0
console.log(Number("      123   \n   ")); // 123
console.log(Number("      123z   \n   ")); // NaN
console.log(Number("           ")); // 0
```

## Логическое

Все "пустые" по смыслу значения становятся `false`: `0`, `""`, `null`, `undefined`, `NaN`.
Все остальное преобразуется в `true`: `1`, `"0"` и т. д.

`"0"` становится `true`, потому что проверяется длина значения, а не его содержимое!

НО! Все объекты преобразуются в `true`:

```js
Boolean({}); // true
Boolean([]); // true
Boolean(function () {}); // true
```
