## `rest` и `spread` операторы

`rest` оператор (...rest) собирает остаточные аргументы в массив с любым названием.

```js
function sumAll(...args) {
  let sum = 0;
  for (let arg in args) sum += arg;
  return sum;
}
```

`spread` оператор (...spread) делает все ровно наоборот - раскрывает массив в список аргументов.

```js
let arr = [3, 5, 1];
console.log(Math.max(...arr)); // 5
```

## arguments

В каждой функции имеется встроенный массив аргументов `arguments`:

```js
function showName() {
  console.log(arguments.length);
  console.log(arguments[0]);
  console.log(arguments[1]);
}

// Вывод: 2, Юлий, Цезарь
showName("Юлий", "Цезарь");

// Вывод: 1, Илья, undefined (второго аргумента нет)
showName("Илья");
```

## Глобальный объект

Глобальный объект предоставляет переменные и функции, доступные в любом месте программы. По умолчанию это те, что встроены в язык или среду исполнения.
В браузере он называется `window`, в Node.js - `global`, в другой среде исполнения может называться иначе.
Если скрипт может выполняться и в другом окружении, лучше будет `globalThis` (стандартизированное имя для глобального объекта).

## Встроенные свойства функции как объекта

- `name` - имя функции
- `length` - количество параметров в функции
- Можно добавлять свои кастомные свойства для функции

```js
function printParams(name) {
  printParams.count++;
  console.log(printParams.name);
  console.log(printParams.length);
  console.log(printParams.count);
}

printParams.count = 0;

printParams(1); // printParams, 1, 1
printParams(1); // printParams, 1, 2
```

Выражение `new Function()` позволяет создавать функцию из текста:

```js
let textFunction = "return a + b;";
const newFunction = new Function("a", "b", textFunction);
console.log(newFunction(1, 2));
```

## Планирование вызова функции

Можно вызывать функцию через определенный промежуток времени.
`setTimeout` - вызов один раз через определенный промежуток времени.

```js
let timerId = setTimeout(func|code, [delay], [arg1], [arg2], ...);
```

где:

- `func|code` - функция или текст функции
- `delay` - задержка в мс
- `arg1...n` - аргументы, передаваемые в функцию

`clearTimeout` отменит выполнение функции с задержкой:

```js
clearTimeout(timerId);
```

`setInterval` - регулярный вызов через определенное количество времени.

```js
let timerId = setInterval(func|code, [delay], [arg1], [arg2], ...);
```

Синтаксис точно такой же, для остановки такого метода планирования нужно использовать `clearTimeout`.

**Важная особенность!** `setInterval` не учитывает время, затраченное на выполнение функции. Поэтому, если функция выполняется дольше задержки, тогда при выходе из нее она запустится мгновенно.
Если необходимо учитывать этот момент, нужно использовать вложенный в функцию `setTimeout`.

## Каррирование

**Каррирование** - это трансформация функций таким образом, чтобы они принимали аргументы не как `f(a, b, c)`, а как `f(a)(b)(c)`.
Мы передаем в функцию каррирования один аргумент, затем эта функция возвращает новую функцию, в которую передается второй аргумент и так по цепочке до конца, пока последняя вложенная функция не вернет результат.

```js
function sum(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}
sum(1)(2)(3); // 6 (аргументы по очереди)
```

```js
function curry(f) {
  return function (a) {
    return function (b) {
      return f(a, b);
    };
  };
}

function sum(a, b) {
  return a + b;
}

let curriedSum = curry(sum);

console.log(curriedSum(1)(2)); // 3
```
