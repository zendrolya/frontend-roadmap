# Методы строк

[⬅️Назад](./14.%20Методы%20чисел.md) | [🏠Содержание](../README.md) | [Вперед➡️](./)

> [!IMPORTANT]
> Строки в JavaScript **иммутабельны** - их нельзя изменить. Все методы возвращают **новую** строку.
>
> ```js
> const str = "hello";
> str[0] = "H";
> console.log(str); // "hello" - не изменилось
> ```

## Доступ к символам

```js
str.length; // длина строки
str[1]; // доступ по индексу (отрицательные = undefined)
str.at(-1); // доступ по индексу с поддержкой отрицательных
str.charCodeAt(0); // код UTF-16 символа по индексу
str.codePointAt(0); // код Unicode символа по индексу
```

## Регистр

```js
str.toLowerCase(); // в нижний регистр
str.toUpperCase(); // в верхний регистр
```

## Поиск

```js
str.indexOf(substr, [pos]); // индекс первого вхождения или -1
str.lastIndexOf(substr, [pos]); // индекс последнего вхождения или -1
str.includes(substr, [pos]); // true/false
str.startsWith(substr, [pos]); // начинается ли с подстроки
str.endsWith(substr, [pos]); // заканчивается ли подстрокой
str.search(regexp); // индекс первого совпадения с регуляркой
str.match(regexp); // массив совпадений
str.matchAll(regexp); // итератор всех совпадений
```

## Получение подстроки

```js
str.slice(start [, end]);      // от start до end (не включительно)
str.substring(start [, end]);  // без отрицательных, меняет местами
str.substr(start [, length]); // УСТАРЕЛ
```

Разница между `slice` и `substring`:

| Поведение             | slice         | substring       |
| --------------------- | ------------- | --------------- |
| Отрицательные индексы | Поддерживает  | Преобразует в 0 |
| start > end           | Возвращает "" | Меняет местами  |

## Замена

```js
str.replace(substr, newSubstr); // первое вхождение
str.replaceAll(substr, newSubstr); // все вхождения
str.replace(regexp, newSubstr); // с регуляркой
```

## Разделение и объединение

```js
str.split(separator, [limit]);  // разбить строку в массив
"a,b,c".split(",");             // ["a", "b", "c"]
"abc".split("");                // ["a", "b", "c"]

str.concat(str2, ...);          // объединить строки
"Hello".concat(" ", "world");   // "Hello world"
```

## Обрезка пробелов

```js
str.trim(); // удаляет пробелы с обоих концов
str.trimStart(); // удаляет пробелы в начале
str.trimEnd(); // удаляет пробелы в конце
```

## Дополнение строк

```js
str.padStart(targetLength, [padString]); // дополнить до длины слева
str.padEnd(targetLength, [padString]); // дополнить до длины справа

"5".padStart(3, "0"); // "005"
"5".padEnd(3, "0"); // "500"
"abc".padStart(5, "-"); // "--abc"
```

## Повторение

```js
str.repeat(count); // повторить строку count раз
"ab".repeat(3); // "ababab"
```

## Сравнение строк

```js
str.localeCompare(str2, [locales], [options]);
```

Возвращает:

- `-1` - `str` идёт до `str2`
- `0` - строки равны
- `1` - `str` идёт после `str2`
