# Логические операторы

[⬅️Назад](./6.%20Сравнение%20типов.md) | [🏠Содержание](../README.md) | [Вперед➡️](./8.%20Функции.md)

## `||` (ИЛИ)

Находит первое истинное значение и возвращает его, иначе вернет последнее.

```js
console.log(null || undefined || NaN); // NaN
console.log(null || 1 || NaN); // 1
```

## `||=` (логическое присваивание ИЛИ)

Если A ложно, то присвоит ему значение B:

```js
let A = 0;
let B = 1;
A ||= B;
console.log(A); // 1
```

## `&&` (И)

Находит первое ложное значение и возвращает его, иначе вернет последнее.

```js
console.log(null && undefined && NaN); // null
console.log(1 && NaN && 1); // NaN
```

## `&&=` (логическое присваивание И)

Если A истинно, присвоит ему значение B.

```js
let A = 1;
let B = 2;
A &&= B;
console.log(A); // 2
```

## `!` (НЕ)

Приводит аргумент к логическому типу, а затем возвращает противоположное значение:

```js
console.log(!null); // true
console.log(!!null); // false
```

## `??` (нулевое слияние)

Пусть значение "определено", если оно не является `null` или `undefined`.
Данный оператор находит первое "определенное" значение и возвращает его, иначе вернет последнее.

```js
console.log(null ?? undefined ?? 1 ?? "1"); // 1
console.log(null ?? undefined ?? null); // null
```

## `??=` (нулевое присваивание)

Присваивает A значение B в том случае, если A не "определено".

```js
let A = null;
let B = 1;
A ??= B;
console.log(A); // 1
```

## Приоритет логических операторов

`&&` имеет приоритет выше, чем `||`, а смешивать `??` с любым из этих операторов нельзя:

```js
console.log(1 || 0 && 1); // 0 && 1 = 0, 1 || 0 = 1
console.log(null || undefined ?? "default"); // SyntaxError
console.log((null || undefined) ?? "default"); // "default"
```
