# Контекст вызова функции

[⬅️Назад](./11.%20Объекты.md) | [🏠Содержание](../README.md) | [Вперед➡️](./13.%20Символы.md)

**`this`** - это ссылка на объект, в контексте которого вызывается функция.
Значение `this` определяется **в момент вызова**, а не в момент объявления функции.

## `this` в разных ситуациях

```js
// 1. Глобальная область (нестрогий режим)
console.log(this); // window

// 2. Глобальная область (strict mode)
("use strict");
console.log(this); // undefined

// 3. Обычная функция
function fn() {
  console.log(this); // window / undefined (strict)
}
fn();

// 4. Метод объекта
const obj = {
  name: "John",
  method() {
    console.log(this.name); // "John" - this = obj
  },
};
obj.method();

// 5. Стрелочная функция - берёт this из внешнего окружения
const outer = {
  name: "Outer",
  method() {
    const arrow = () => console.log(this.name);
    arrow(); // "Outer" - this из method()
  },
};
outer.method();

// 6. Конструктор
function User(name) {
  this.name = name; // this = новый объект
}
new User("John");

// 7. Обработчик события
button.addEventListener("click", function () {
  console.log(this); // button
});

// 8. setTimeout
setTimeout(function () {
  console.log(this); // window / undefined (strict)
}, 0);
```

Обычная функция внутри метода теряет `this`:

```js
const obj = {
  name: "John",
  hello() {
    function Hello() {
      console.log("Hello " + this.name);
    }
    const Hello2 = () => console.log("Hello " + this.name);

    setTimeout(Hello, 1000); // undefined
    setTimeout(Hello2, 1000); // "Hello John"
  },
};

obj.hello();
```

> [!IMPORTANT]
> Стрелочная функция не имеет своего `this`. Она берет `this` из внешнего лексического окружения - из того места, где была создана.
> Даже если стрелочная функция записана внутри объекта, её `this` не будет указывать на этот объект.

## Потеря `this`

```js
const user = {
  name: "John",
  greet() {
    console.log(this.name);
  },
};

// Работает
user.greet(); // "John"

// Потеря this
const fn = user.greet;
fn(); // undefined

// Потеря this в setTimeout
setTimeout(user.greet, 0); // undefined

// Решения:
setTimeout(() => user.greet(), 0); // Стрелочная функция
setTimeout(user.greet.bind(user), 0); // bind
```

## Привязка контекста

Методы `call`, `apply` и `bind` находятся в Function.prototype, поэтому доступны всем функциям.

```js
const dev = {
  name: "John",
  salary: 2000,
  updateSalary(sum) {
    this.salary += sum;
    console.log(this.salary);
  },
};

const manager = {
  name: "Maria",
  salary: 500,
};

dev.updateSalary.call(manager, 100); // начиная со второго аргумента передаются параметры функции, функция вызывается сразу!
dev.updateSalary.apply(manager, [100]); // делает ровно то же самое, но передавать параметры нужно массивом, функция вызывается сразу!
manager.updateSalary = dev.updateSalar.bind(manager); // возвращает новую функцию с привязанным this от manager, функция не вызывается сразу!
```
