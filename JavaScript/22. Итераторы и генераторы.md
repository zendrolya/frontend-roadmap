## Итерируемые объекты

**Итерируемый объект** - это объект, который можно перебрать в цикле `for...of`.

Сами массивы и строки - итерируемые. Но можно сделать итерируемым любой объект, если добавить ему специальный метод `Symbol.iterator`.

### Как работает `for...of`

Когда запускается `for...of` по объекту:

1. Вызывается метод `obj[Symbol.iterator]()` - один раз в начале
2. Этот метод возвращает итератор - объект с методом `next()`
3. Далее `for...of` работает только с итератором, вызывая `next()` на каждой итерации
4. `next()` должен вернуть объект вида `{ done: Boolean, value: any }`
   - `done: false` - есть еще значения, `value` содержит очередное
   - `done: true` - перебор завершен

> [!IMPORTANT]
> Разделение ответственности: у самого объекта нет `next()`.
> `next()` есть у итератора, который возвращает `Symbol.iterator`.

```js
const range = {
  from: 1,
  to: 5,

  [Symbol.iterator]() {
    // возвращаем объект-итератор
    return {
      current: this.from,
      last: this.to,

      next() {
        if (this.current <= this.last) {
          return { done: false, value: this.current++ };
        } else {
          return { done: true };
        }
      },
    };
  },
};

for (const num of range) {
  console.log(num); // 1, 2, 3, 4, 5
}
```

### Бесконечные итераторы

`next()` может возвращать значения бесконечно. Цикл `for...of` с таким итератором тоже будет бесконечным - прервать можно через `break`.

```js
const infinite = {
  [Symbol.iterator]() {
    let i = 0;
    return {
      next() {
        return { done: false, value: i++ };
      },
    };
  },
};

for (const num of infinite) {
  if (num > 5) break;
  console.log(num); // 0, 1, 2, 3, 4, 5
}
```

### Явный вызов итератора

Итератор можно использовать вручную - это дает больше контроля:

```js
const str = "Привет";
const iterator = str[Symbol.iterator]();

console.log(iterator.next()); // { value: "П", done: false }
console.log(iterator.next()); // { value: "р", done: false }
// ... можно прерваться и продолжить позже
```

## Генераторы

Генератор - это функция, которая может возвращать множество значений по мере необходимости.

### Объявление

```js
function* generateSequence() {
  yield 1;
  yield 2;
  return 3;
}
```

### Как работает генератор

Когда вызывается функция-генератор, код не выполняется. Вместо этого возвращается объект-генератор:

```js
const generator = generateSequence();
console.log(generator); // Object [Generator] {}
```

Основной метод - `next()`:

```js
console.log(generator.next()); // { value: 1, done: false }
console.log(generator.next()); // { value: 2, done: false }
console.log(generator.next()); // { value: 3, done: true }
```

1. `next()` запускает код до ближайшего `yield`
2. Возвращает `{ value, done }`
3. Повторный `next()` продолжает с места остановки
4. Когда функция завершается (через `return` или конец), `done: true`

> [!IMPORTANT]
> Значение из `return` не попадает в `for...of`! Перебор через `for...of` игнорирует последнее значение с `done: true`.
>
> ```js
> for (const val of generateSequence()) {
>   console.log(val); // 1, 2 — но НЕ 3
> }
> ```
>
> Если нужно отдать все значения- используйте `yield` вместо `return`.

### Генератор - итерируемый объект

У генератора есть `Symbol.iterator`, поэтому он работает с `for...of` и spread-оператором:

```js
function* gen() {
  yield 1;
  yield 2;
  yield 3;
}

console.log([...gen()]); // [1, 2, 3]
console.log(Math.max(...gen())); // 3
```

Генератор сильно упрощает создание итерируемых объектов:

```js
const range = {
  from: 1,
  to: 5,

  *[Symbol.iterator]() {
    // генератор вместо объекта с next()
    for (let i = this.from; i <= this.to; i++) {
      yield i;
    }
  },
};

console.log([...range]); // [1, 2, 3, 4, 5]
```

### Бесконечные генераторы

```js
function* naturals() {
  let n = 0;
  while (true) {
    yield n++;
  }
}

const gen = naturals();
console.log(gen.next().value); // 0
console.log(gen.next().value); // 1
console.log(gen.next().value); // 2
```

### Композиция генераторов (`yield*`)

```js
function* genA() {
  yield 1;
  yield 2;
}

function* genB() {
  yield 0;
  yield* genA(); // делегируем genA
  yield 3;
}

console.log([...genB()]); // [0, 1, 2, 3]
```

Это прозрачно - `genB` как будто сам генерирует значения из `genA`.

### `yield` - дорога в обе стороны

Это главное отличие генераторов от обычных функций: `yield` не только возвращает значение наружу, но и принимает значение извне.

```js
function* dialog() {
  const name = yield "Как тебя зовут?";
  const age = yield `Привет, ${name}! Сколько тебе лет?`;
  return `${name}, ${age} лет`;
}

const gen = dialog();

console.log(gen.next().value); // "Как тебя зовут?"
console.log(gen.next("Иван").value); // "Привет, Иван! Сколько тебе лет?"
console.log(gen.next(25).value); // "Иван, 25 лет"
```

Как это работает:

1. Первый `next()` - всегда без аргумента. Запускает код до первого `yield`
2. `next(arg)` - передает `arg` в генератор как результат текущего `yield`
3. Выполнение продолжается до следующего `yield`

## Асинхронные итераторы

**Асинхронные итераторы** - для данных, которые приходят с задержкой (например, постранично из сети).

```js
const range = {
  from: 1,
  to: 5,

  [Symbol.asyncIterator]() {
    return {
      current: this.from,
      last: this.to,

      async next() {
        await new Promise((r) => setTimeout(r, 1000)); // пауза 1 сек
        if (this.current <= this.last) {
          return { done: false, value: this.current++ };
        } else {
          return { done: true };
        }
      },
    };
  },
};

(async () => {
  for await (const val of range) {
    console.log(val); // 1, 2, 3, 4, 5 (с задержкой)
  }
})();
```

## Асинхронные генераторы

**Асинхронный генератор** - это `async function*`. Внутри можно использовать `await`, а также обычный `yield`.

```js
async function* fetchCommits(repo) {
  let url = `https://api.github.com/repos/${repo}/commits`;

  while (url) {
    const response = await fetch(url, {
      headers: { "User-Agent": "Our script" },
    });

    const body = await response.json();

    // Ссылка на следующую страницу — в заголовке Link
    let nextPage = response.headers.get("Link")?.match(/<(.*?)>; rel="next"/);
    url = nextPage?.[1];

    for (const commit of body) {
      yield commit; // отдаём по одному коммиту
    }
  }
}

// Использование
for await (const commit of fetchCommits(
  "javascript-tutorial/en.javascript.info",
)) {
  console.log(commit.author.login);
  if (++count > 50) break; // ограничим
}
```

Что здесь происходит:

- Внешний код просто делает `for await...of` - и получает коммиты
- Внутри генератор сам разбирается с постраничными запросами
- Логика запросов скрыта от потребителя

> [!TIP]
> Асинхронные генераторы - естественный способ работы с потоками данных (постраничная загрузка, чтение файлов частями, WebSocket).
