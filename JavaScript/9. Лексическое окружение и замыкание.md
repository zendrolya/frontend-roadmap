## Контекст вызова функции (execution context) и области видимости функции (scope)

Контекст вызова функции (execution context) создается при каждом вызове функции.
При передаче параметров, они копируются в локальную область видимости функции.

![Контекст вызова функции](attachments/image.png)

Затем значение из `return` записывается в переменную `result`, которая хранится в глобальной области видимости, а локальная область видимости функции удалится:

![В result записывается результат функции в операторе return, а локальная область видимости функции удаляется](attachments/image-1.png)

> [!IMPORTANT]
> Локальная область видимости **не всегда удаляется** сразу. Если на переменные ссылается замыкание, они сохраняются в памяти до тех пор, пока существует ссылка на замыкание.

## Лексическое окружение

У каждой функции, блока кода {...} и скрипта в целом есть свое лексическое окружение (Lexical Environment) - по сути, объект.

Лексическое окружение состоит из двух частей:

- **Environment Record** - объект, в котором как свойства хранятся все локальные переменные и другая информация.
- **Ссылка на внешнее лексическое окружение** `[[OuterEnv]]`.

### Особенности

- Переменная - это одно из свойств **Environment Record**, которое меняется при изменении переменной.
- Function Declaration инициализируется сразу же и полностью в **Environment Record** (свойство hoisting).
- Когда запускается функция, для нее сразу же создается свое лексическое окружение.
- `var` - переменная создается в Environment Record функции при входе в нее или скрипте.
- `let`/`const` - переменная создаётся в Environment Record блока, но до объявления находится в TDZ.

## Замыкание

**Замыкание** - это механизм, при котором функция запоминает свое внешнее лексическое окружение и может получить к нему доступ, даже после того, как внешняя функция завершилась.

- Каждая функция при создании получает скрытое свойство `[[Environment]]`, которое хранит ссылку на лексическое окружение **места её создания**.
- Когда функция обращается к переменной, которой нет в её собственном окружении, движок ищет её по цепочке `[[Environment]]`.
