## Создание

```js
const arr = new Array(); // через конструктор
const arr = []; // литеральная нотация (рекомендуется)
const arr = [1, 2, 3];
const arr = new Array(3); // [ , , ] - массив с 3 пустыми слотами
const arr = Array.of(3); // [3] - массив с одним элементом
```

## Методы

### Добавление и удаление

```js
arr.push(el); // добавить в конец, возвращает новую длину
arr.pop(); // удалить последний, возвращает удаленный элемент
arr.shift(); // удалить первый, возвращает удаленный элемент
arr.unshift(el); // добавить в начало, возвращает новую длину
```

### Доступ к элементам

```js
arr.length; // длина массива
arr[1]; // доступ по индексу
arr.at(-1); // доступ по индексу с поддержкой отрицательных
```

### Очистка массива

```js
arr.length = 0; // очистка
arr.splice(0); // тоже очистка
arr = []; // если объявлен через let
```

### Перебор массива

```js
// for...of - значения
for (const el of arr) {
  console.log(el);
}

// forEach - без возврата
arr.forEach((item, index, array) => {
  console.log(item, index);
});

// for...in - индексы (не рекомендуется для массивов!)
for (const index in arr) {
  console.log(index);
}
```

1. Цикл for..in выполняет перебор всех свойств объекта, а не только цифровых.
   В браузере и других программных средах также существуют так называемые "псевдомассивы" - объекты, которые выглядят, как массив. То есть, у них есть свойство length и индексы, но они также могут иметь дополнительные нечисловые свойства и методы, которые нам обычно не нужны. Тем не менее, цикл for..in выведет и их. Поэтому, если нам приходится иметь дело с объектами, похожими на массив, такие "лишние" свойства могут стать проблемой.
2. Цикл for..in оптимизирован под произвольные объекты, не массивы, и поэтому в 10-100 раз медленнее.

### Строковое преобразование

```js
arr.toString(); // вызывает join(",") по умолчанию
arr.join(sep); // склеивает через разделитель
```

```js
[1, 2, 3].toString(); // "1,2,3"
[1, null, 2, undefined, 3].toString(); // "1,,2,,3"
[1, 2, 3].join("-"); // "1-2-3"
[1, 2, 3].join(""); // "123"
```

### Преобразование в массив

```js
str.split(sep); // строка => массив
Array.from(iterable); // итерируемое => массив
[...iterable]; // spread
Array.of(el1, el2); // из аргументов
```

```js
"a,b,c".split(","); // ["a", "b", "c"]
Array.from("hello"); // ["h", "e", "l", "l", "o"]
Array.from({ length: 3 }, (_, i) => i); // [0, 1, 2]
[...new Set([1, 2, 2])]; // [1, 2]
Array.of(1, 2, 3); // [1, 2, 3]
```

### Извлечение подмассива

```js
arr.slice([start], [end]); // копия от start до end (не включительно)
arr.splice(start, deleteCount, ...items); // мутация исходного массива
```

```js
const arr = [1, 2, 3, 4, 5];

arr.slice(1, 3); // [2, 3] - не мутирует
arr.slice(-2); // [4, 5]

// splice мутирует и возвращает удалённые элементы
const removed = arr.splice(1, 2, "a", "b");
console.log(arr); // [1, "a", "b", 4, 5]
console.log(removed); // [2, 3]
```

### Поиск

```js
arr.indexOf(el, [from]); // индекс первого вхождения или -1
arr.lastIndexOf(el, [from]); // индекс последнего вхождения или -1
arr.includes(el, [from]); // true/false (работает с NaN)
arr.find(callback); // первый подходящий элемент или undefined
arr.findIndex(callback); // индекс первого подходящего или -1
arr.findLast(callback); // последний подходящий
arr.findLastIndex(callback); // индекс последнего подходящего
```

```js
[1, 2, 3].indexOf(2); // 1
[1, 2, 3].includes(2); // true
[NaN].indexOf(NaN); // -1
[NaN].includes(NaN); // true

const users = [{ name: "John" }, { name: "Jane" }];
users.find((u) => u.name === "Jane"); // { name: "Jane" }
users.findIndex((u) => u.name === "Jane"); // 1
```

### Преобразование элементов

```js
arr.map(callback); // новый массив из результатов функции
arr.filter(callback); // новый массив из подходящих элементов
arr.flat(depth); // разворачивает вложенные массивы
arr.flatMap(callback); // map + flat(1)
```

```js
[1, 2, 3].map((n) => n * 2); // [2, 4, 6]
[1, 2, 3, 4].filter((n) => n % 2); // [1, 3]
[1, [2, [3, [4]]]].flat(2); // [1, 2, 3, [4]]
[1, [2, [3, [4]]]].flat(Infinity); // [1, 2, 3, 4]
[1, 2, 3].flatMap((n) => [n, n * 2]); // [1, 2, 2, 4, 3, 6]
```

### Агрегация

```js
arr.reduce((acc, item, index, array) => {...}, [initial]);
arr.reduceRight((acc, item, index, array) => {...}, [initial]);
```

```js
[1, 2, 3, 4].reduce((acc, n) => acc + n, 0); // 10
[1, 2, 3, 4].reduceRight((acc, n) => acc + n, 0); // 10
```

### Проверка условиий

```js
arr.some(callback); // true, если хотя бы один подходит
arr.every(callback); // true, если все подходят
```

```js
[1, 2, 3].some((n) => n > 2); // true
[1, 2, 3].every((n) => n > 0); // true
[1, 2, 3].every((n) => n > 2); // false
```

### Сортировка и разворот

```js
arr.sort([compareFn]); // мутирует!
arr.reverse(); // мутирует!
arr.toSorted([compareFn]); // ES2023 - не мутирует
arr.toReversed(); // ES2023 - не мутирует
```

> [!WARNING]
> Без функции сравнения sort() сортирует по строкам:

### Объединение

```js
arr1.concat(arr2, arr3); // новый массив
[...arr1, ...arr2]; // spread
```

### Заполнение и копирование

```js
arr.fill(value, [start], [end]); // заполняет значением
arr.copyWithin(target, [start], [end]); // копирует часть в другую часть
```

```js
[1, 2, 3, 4].fill(0, 1, 3); // [1, 0, 0, 4]
[1, 2, 3, 4, 5].copyWithin(0, 3); // [4, 5, 3, 4, 5]
```

### Проверка на массив

```js
Array.isArray(arr); // true/false
```

### Мутирующие и немутирующие методы

| Мутируют         | Не мутируют       |
| ---------------- | ----------------- |
| push, pop        | slice, concat     |
| shift, unshift   | map, filter       |
| splice           | reduce, forEach   |
| sort, reverse    | find, some, every |
| fill, copyWithin | flat, flatMap     |
