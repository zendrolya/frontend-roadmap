# Регулярные выражения

[⬅️Назад](./16.%20Массивы.md) | [🏠Содержание](../README.md) | [Вперед➡️](./18.%20Работа%20с%20DOM.md)

**Регулярное выражение** - это шаблон для поиска и замены в строках.

## Создание

```js
const regex1 = /\w+/; // литеральная нотация (рекомендуется)
const regex2 = new RegExp("\\w+"); // через конструктор (для динамических)
```

> [!TIP]
> `String.raw` используется для улучшения читаемости регулярных выражений:
>
> ```js
> new RegExp(String.raw`\d+`); // вместо "\\d+"
> ```

## Флаги

| Флаг | Название   | Что делает                                        |
| ---- | ---------- | ------------------------------------------------- |
| g    | global     | Все совпадения                                    |
| i    | ignoreCase | Игнорирует регистр                                |
| m    | multiline  | ^ и $ для каждой строки (многострочный режим)     |
| s    | dotAll     | режим, при котором `.` может соответствовать `\n` |
| u    | unicode    | Правильная работа с Unicode                       |
| y    | sticky     | Поиск строго с позиции lastIndex                  |
| d    | hasIndices | Добавляет индексы групп                           |

## Специальные классы

|        |                                                 |
| ------ | ----------------------------------------------- |
| `/\d/` | цифра [0-9]                                     |
| `/\D/` | не цифра                                        |
| `/\w/` | буква, цифра, _ [A-Za-z0-9_]                    |
| `/\W/` | не \w                                           |
| `/\s/` | пробел, таб, \n                                 |
| `/\S/` | не \s                                           |
| `/\b/` | граница слова                                   |
| `/\B/` | не граница слова                                |
| `/./`  | любой символ кроме \n (с флагом s - включая \n) |

## Квантификаторы

|          |              |
| -------- | ------------ |
| /a\*/    | 0 или больше |
| /a+/     | 1 или больше |
| /a?/     | 0 или 1      |
| /a{3}/   | ровно 3      |
| /a{2,5}/ | от 2 до 5    |
| /a{2,}/  | 2 или больше |

## Группы символов и якоря

|               |                      |
| ------------- | -------------------- |
| /[abc]/       | a, b или c           |
| /[^abc]/      | не a, b, c           |
| /[a-z]/       | диапазон             |
| /[a-zA-Z0-9]/ | несколько диапазонов |
| /^abc/        | начало строки        |
| /abc$/        | конец строки         |

## Группы захвата

```js
const date = "2024-01-15";
const regex = /(\d{4})-(\d{2})-(\d{2})/;
const match = date.match(regex);

match[0]; // "2024-01-15" - все совпадение
match[1]; // "2024"
match[2]; // "01"
match[3]; // "15"
```

## Именование группы

```js
const regex = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const match = "2024-01-15".match(regex);

match.groups.year; // "2024"
match.groups.month; // "01"
match.groups.day; // "15"
```

## Методы `RegExp`

```js
regex.test(str); // true/false
regex.exec(str); // массив с деталями или null
```

## Методы строк с regex

```js
str.match(regex);        // массив совпадений
str.matchAll(regex);     // итератор всех совпадений с группами
str.search(regex);       // индекс первого совпадения
str.replace(regex, ...); // замена
str.replaceAll(regex, ...); // замена всех (ES2021)
str.split(regex);        // разделение
```

## Замена

```js
str.replace(/JS/g, "php"); // все вхождения
str.replace(/(\d{4})-(\d{2})-(\d{2})/, "$3.$2.$1"); // с группами
str.replace(/\d/g, (m) => `[${m}]`); // с функцией
```
