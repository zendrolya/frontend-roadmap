# "use strict"

[⬅️Назад](./1.%20Введение%20в%20JS.md) | [🏠Содержание](../README.md) | [Вперед➡️](./3.%20Переменные%20и%20области%20видимости.md)

**Строгий режим (strict mode)** - это специальный режим работы JavaScript, в котором применяются дополнительные правила и ограничения для улучшения безопасности и предотвращения ошибок.

Строгий режим был добавлен в стандарте ECMAScript 5 (ES5) в 2009 году.
По умолчанию он не применяется, чтобы не ломать старый код, написанный до его появления.

## Что дает строгий режим

1. **Запрещает неявное создание глобальных переменных.** Присвоение значения необъявленной переменной выбрасывает `ReferenceError`.
2. **Превращает "тихие" ошибки в исключения.** Присвоение значения свойству, доступному только для чтения, удаление неудаляемого свойства, добавление свойства в нерасширяемый объект - все это выбрасывает ошибки.
3. Если Function Declaration находится в блоке {...}, то она доступна везде внутри него, но не снаружи.
4. **Запрещает дублирование имён параметров функции** и использование зарезервированных слов (`implements`, `interface`, `let`, `package`, `private`, `protected`, `public`, `static`, `yield`) в качестве имен.
5. **Меняет поведение `this`.** В обычной функции (не методе) `this` равен `undefined`, а не глобальному объекту.
6. **Меняет поведение `eval`.** Код внутри `eval` не создаёт переменные в окружающей области видимости.
7. **Позволяет движку лучше оптимизировать код.** Строгий режим упрощает анализ областей видимости.

## Активация строгого режима

Директива `"use strict"` может быть двух видов:

**Глобально (для всего скрипта):**

```js
"use strict";
// весь код ниже - в строгом режиме
```

**Локально (только внутри функции):**

```js
function strictFunction() {
  "use strict";
  // только этот код - в строгом режиме
}

function normalFunction() {
  // этот код - в обычном режиме
}
```

> [!IMPORTANT]
> **Классы** и **модули** (ES6) автоматически включают строгий режим - писать "use strict" в них не нужно.
>
> **Отменить действие строгого режима** после включения **нельзя**. Но если скрипт не поддерживает строгий режим, директива просто игнорируется, и код продолжает работать.
