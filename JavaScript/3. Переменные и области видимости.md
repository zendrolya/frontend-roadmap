# Переменные и области видимости

[⬅️Назад](./2.%20use%20strict.md) | [🏠Содержание](../README.md) | [Вперед➡️](./4.%20Типы%20данных.md)

## Основные правила переменных

- camelCase в названии
- Допустимые названия включают: $, \_, буквы, цифры
- Первый символ не должен быть цифрой
- Регистр символов имеет значение (myParam и MYPARAM - разные переменные)
- В strict режиме не можем использовать необъявленные переменные
- Повторное объявление через `let`/`const` вызывает `SyntaxError`, `var` допускает повторное объявление - оно игнорируется

## `const`

`const` - переменные, в которых запрещено переприсваивание (мутация содержимого разрешена).

Можно использовать константы в качестве псевдонимов для трудно запоминаемых или "магических" значений (например, цветов в шестнадцатеричном формате).
В таком случае пишем название заглавными буквами с использованием нижнего подчеркивания:

```js
const COLOR_ORANGE = "#FF7F00";
```

В остальных же случаях используем тот же camelCase, что и для обычных переменных.

## Области видимости переменных

### Глобальная область

Переменные, объявленные вне функций и блоков, доступны везде:

```js
var globalVar = "глобальная";
let globalLet = "тоже глобальная";

function test() {
  console.log(globalVar); // "глобальная"
  console.log(globalLet); // "тоже глобальная"
}
```

`var` в глобальной области становится свойством `window`:

```js
var a = 5;
console.log(window.a); // 5

let b = 10;
console.log(window.b); // undefined
```

### Блок кода

Если `let`/`const` переменная объявлена в блоке кода, то она видна только внутри него.

```js
{
  let message = "Hello"; // переменная видна только в этом блоке
  console.log(message); // Hello
}

console.log(message); // ReferenceError: message is not defined
```

### Функция

Переменные, объявленные внутри функции, видны только внутри нее.

```js
function sayHi() {
  let phrase = "Привет"; // локальная переменная
  console.log(phrase); // Привет
}

sayHi();
console.log(phrase); // ReferenceError: phrase is not defined
```

## `var`

Для `var` не существует блочной области видимости, это ключевое слово ограничивается лишь функцией или всем скриптом в целом.
`var` допускает повторное объявление, но игнорирует его.

`var` обрабатывается в начале запуска функции/скрипта, то есть такие переменные считаются объявленными с самого начала, вне зависимости от того, где реально находится объявление.

```js
function sayHi() {
  phrase = "Привет";
  console.log(phrase);
  var phrase;
}
sayHi();
```

Эквивалентно:

```js
function sayHi() {
  var phrase;
  phrase = "Привет";
  console.log(phrase);
}
sayHi();
```

Это поведение называется \*"hoisting" (всплытие, поднятие)\*\*, потому что все объявления переменных `var` "всплывают" на самый верх функции.

> [!TIP]
> **Хойстинг** - механизм, при котором объявления переменных и функций "поднимаются" в начало своей области видимости.

Важный момент: такое поведение касается только объявления, присваивание значения происходит на своем месте:

```js
console.log(a); // undefined
var a = 5;
console.log(b); // ReferenceError: Cannot access 'b' before initialization
let b = 10;
```

Технически `let`/`const` тоже хойстятся, но попадают в **TDZ (Temporal Dead Zone)** - временную мертвую зону,использовать их до объявления нельзя.
