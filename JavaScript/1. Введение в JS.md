# Введение в JS

[🏠Содержание](../README.md) | [Вперед➡️](./2.%20use%20strict.md)

Официальный стандарт ECMA: https://262.ecma-international.org

**JavaScript** - фактически реализация этого стандарта ECMA.

**ES6** - стандарт ECMAScript, начиная с 2015 года. ES5 и ES6 имеют разительные отличия в синтаксисе, а далее уже идут версии по годам, которые концептуально не отличаются, а лишь добавляют новые возможности.

**JavaScript (JS)** - это легковесный интерпретируемый (или JIT-компилируемый) язык программирования с функциями первого класса.
Наиболее широкое применение находит как язык сценариев веб-страниц, но также используется и в других программных продуктах, например, Node.js или Apache CouchDB.

> [!TIP]
> Функции считаются **первым классом**, если с ними можно работать как с переменными.
> Например, передача в качестве аргумента другим функциям, возврат из функции, присваивание переменной в качестве значения.

**Характеристики JS как языка:**

- прототипно-ориентированный;
- динамически типизированный;
- мультипарадигменный - поддерживает разные стили программирования, в частности: ООП, императивный и декларативный (например, функциональный).

Для запуска JS-скриптов необходим **движок**, принцип работы которого следующий:

1. Чтение (парсинг) текста скрипта.
2. Преобразование (компиляция) скрипта в машинный язык.
3. Машинный код запускается и работает.
