# localStorage, sessionStorage, document.cookie, IndexedDB

[⬅️Назад](./18.%20Работа%20с%20DOM.md) | [🏠Содержание](../README.md) | [Вперед➡️](./20.%20Асинхронный%20JS.md)

## Сравнение способов хранения

| Хранилище         | Объём   | Срок жизни          | Синхронность | Доступ       |
| ----------------- | ------- | ------------------- | ------------ | ------------ |
| `localStorage`    | 5-10 МБ | Бессрочно           | Синхронно    | Из JS        |
| `sessionStorage`  | 5-10 МБ | До закрытия вкладки | Синхронно    | Из JS        |
| `document.cookie` | ~4 КБ   | По настройке        | Синхронно    | Из JS и HTTP |
| `IndexedDB`       | 50+ МБ  | Бессрочно           | Асинхронно   | Из JS        |

Session Storage отличается от Local тем, что хранит информацию только в рамках сессии (одной вкладки). Как только пользователь закрывает браузер или вкладку, хранилище очищается.
В остальном все методы для этих двух типов хранилищ одинаковые.

```js
localStorage.setItem("key", "value"); // запись данных
localStorage.getItem("key"); // получение данных
localStorage.clear(); // очистка всего содержимого localStorage
```

## `localStorage` и `sessionStorage`

### Отличия

- **`localStorage`** - данные сохраняются **бессрочно** (до явной очистки).
- **`sessionStorage`** - данные живут **до закрытия вкладки**.

**`sessionStorage`:**

- Привязан к **вкладке** (не к окну)
- **Сохраняется** при перезагрузке страницы
- **Копируется** в новую вкладку при открытии через `Ctrl+Click` по ссылке
- Данные **разных вкладок** не пересекаются

### Методы

Для sessionStorage одинаковые.

```js
localStorage.setItem("key", "value"); // запись
localStorage.getItem("key"); // чтение
localStorage.removeItem("key"); // удалить один ключ
localStorage.clear(); // удалить всё
localStorage.key(0); // ключ по индексу
localStorage.length; // количество ключей
```

> [!IMPORTANT]
> `localStorage` и `sessionStorage` хранят только строки. Объекты нужно сериализовать:
>
> ```js
> // Запись
> localStorage.setItem("user", JSON.stringify({ name: "John" }));
>
> // Чтение
> const user = JSON.parse(localStorage.getItem("user"));
>
> // Числа тоже становятся строками
> localStorage.setItem("count", 5);
> typeof localStorage.getItem("count"); // "string"
> ```

### Событие `storage`

Срабатывает только в других вкладках при изменении `localStorage`:

```js
window.addEventListener("storage", (event) => {
  console.log(event.key); // ключ
  console.log(event.oldValue); // старое значение
  console.log(event.newValue); // новое значение
  console.log(event.url); // URL вкладки, где произошло изменение
});
```

## `document.cookie`

Cookies - маленькие фрагменты данных, которые отправляются на сервер с каждым HTTP-запросом.

### Запись

```js
document.cookie = "name=John";
document.cookie = "age=20; max-age=3600"; // 1 час
document.cookie = "token=abc; path=/; secure; samesite=strict";
```

### Чтение

```js
console.log(document.cookie); // "name=John; age=20; token=abc"
```

### Удаление

```js
document.cookie = "name=; max-age=0";
```

> [!WARNING]
> `document.cookie` работает неудобно:
> Запись добавляет cookie, а не заменяет все
> Чтение возвращает все cookies одной строкой
> Нельзя удалить конкретную cookie - только установить `max-age=0`
> Нет метода `clear()`

### Атрибуты cookie

| Атрибут    | Описание                                 |
| ---------- | ---------------------------------------- |
| `max-age`  | Время жизни в секундах                   |
| `expires`  | Дата истечения                           |
| `path`     | Путь, для которого действует cookie      |
| `domain`   | Домен                                    |
| `secure`   | Только по HTTPS                          |
| `samesite` | Защита от CSRF (`strict`, `lax`, `none`) |
| `httpOnly` | Недоступна из JS (только сервер)         |

> [!TIP]
> Для удобной работы с cookies используйте библиотеки: `js-cookie`, `universal-cookie`.

## IndexedDB

**IndexedDB** - это встроенная в браузер низкоуровневая база данных для хранения больших объемов структурированных данных, включая файлы и Blob-объекты. В отличие от `localStorage`, она работает асинхронно и не блокирует главный поток, что критично для производительности.

### Зачем нужен IndexedDB

| Проблема с localStorage  | Как решает IndexedDB                           |
| ------------------------ | ---------------------------------------------- |
| Только строки (5-10 МБ)  | Любые структурированные объекты, файлы, Blob   |
| Синхронный, блокирует UI | Асинхронный, не блокирует главный поток        |
| Нет транзакций           | Полноценные транзакции с откатом               |
| Нет индексов для поиска  | Индексы по любому свойству для быстрого поиска |

Объем: обычно не менее 250 МБ, в некоторых браузерах - до 60% свободного места на диске.

### Ключевые концепции

| Термин       | Аналог в SQL   | Описание                                    |
| ------------ | -------------- | ------------------------------------------- |
| Database     | База данных    | Контейнер для хранилищ                      |
| Object Store | Таблица        | Хранит записи (объекты)                     |
| Key Path     | Первичный ключ | Свойство, уникально идентифицирующее запись |
| Index        | Индекс         | Ускоряет поиск по другим свойствам          |
| Transaction  | Транзакция     | Группа операций, атомарная                  |
| Cursor       | Курсор         | Итератор для перебора записей               |
| Request      | —              | Асинхронный запрос (событие success/error)  |

#### Создание и открытие базы

```js
const request = indexedDB.open("myDB", 1);

// Срабатывает при создании или обновлении версии
request.onupgradeneeded = (event) => {
  const db = event.target.result;

  // Создаём хранилище с ключом id
  const store = db.createObjectStore("users", { keyPath: "id" });

  // Создаём индекс по имени
  store.createIndex("name", "name", { unique: false });
};

request.onsuccess = (event) => {
  const db = event.target.result;
  console.log("База открыта");
};

request.onerror = (event) => {
  console.error("Ошибка:", event.target.error);
};
```

#### Основные операции (CRUD)

**Добавление**

```js
const tx = db.transaction(["users"], "readwrite");
const store = tx.objectStore("users");

const request = store.add({ id: 1, name: "John", age: 30 });
request.onsuccess = () => console.log("Добавлено");
request.onerror = () => console.log("Ошибка: ключ уже существует");
```

**Чтение**

```js
const tx = db.transaction(["users"], "readonly");
const store = tx.objectStore("users");

const request = store.get(1);
request.onsuccess = () => {
  console.log(request.result); // { id: 1, name: "John", age: 30 }
};
```

**Обновление**

```js
const tx = db.transaction(["users"], "readwrite");
const store = tx.objectStore("users");

store.put({ id: 1, name: "John", age: 31 }); // Перезапишет запись с id: 1
```

**Удаление**

```js
const tx = db.transaction(["users"], "readwrite");
const store = tx.objectStore("users");

store.delete(1); // Удалить по ключу
```

> [!IMPORTANT]
> Все операции выполняются внутри транзакции.
> Транзакция автоматически коммитится, когда все запросы завершены

### Курсоры - перебор записей

```js
const tx = db.transaction(["users"], "readonly");
const store = tx.objectStore("users");

const request = store.openCursor();

request.onsuccess = (event) => {
  const cursor = event.target.result;
  if (cursor) {
    console.log(cursor.key, cursor.value);
    cursor.continue(); // перейти к следующей записи
  } else {
    console.log("Все записи перебраны");
  }
};
```

> [!TIP]
> Для простого получения всех записей используйте `getAll()`:
>
> ```js
> store.getAll().onsuccess = (e) => console.log(e.target.result);
> ```

### Индексы - поиск по не-ключевым свойствам

```js
// Создание индекса (в onupgradeneeded)
store.createIndex("name", "name", { unique: false });

// Поиск по индексу
const index = store.index("name");
index.get("John").onsuccess = (e) => console.log(e.target.result);
```

### Транзакции

```js
const tx = db.transaction(["users", "posts"], "readwrite");

tx.oncomplete = () => console.log("Транзакция завершена");
tx.onerror = () => console.log("Ошибка — откат");
tx.onabort = () => console.log("Прервана");

// Если один запрос упадет - вся транзакция откатится [citation:3]
```

## Безопасность

`localStorage` и `sessionStorage` не защищены:

- Доступны любому JS-коду на странице (уязвимость к XSS)
- Не шифруются
- Не имеют срока жизни

Никогда **не храните** в них пароли, токены доступа, персональные данные.
Для сессий используйте **httpOnly cookies**.

## Когда что использовать

| Задача                       | Решение                 |
| ---------------------------- | ----------------------- |
| Настройки темы, языка        | localStorage            |
| Данные формы в рамках сессии | sessionStorage          |
| Токены аутентификации        | httpOnly cookie         |
| Большие объёмы данных        | IndexedDB               |
| Кэш запросов                 | Cache API или IndexedDB |
