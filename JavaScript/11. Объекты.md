## Основные операции

### Создание объекта

```js
const user = new Object(); // конструктор объекта
const user = {}; // литеральная нотация
```

### Создание свойства

```js
const user = {
  name: "John",
  "Two words": "value",
};

user.age = 20;
user["Some Text"] = "Some value";
```

### Удаление свойства

```js
const user = {
  name: "John",
  age: 20,
};

delete user.age;
console.log(user); // { name: 'John' }
```

### Некоторые особенности

- Имя свойства может состоять из нескольких слов, тогда используем кавычки для его задания.
- Объект, объявленный как `const` не может быть переприсвоен, но его свойства можно изменять.
- Квадратные скобки позволяют вычислять имя свойства:

```js
const key = "name";
const user = { [key]: "John" }; // { name: "John" }
```

- Если название свойства и его значение совпадают, можно написать сокращенный вариант (`name` вместо `name: name`).
- Свойства с целыми числами упорядочиваются по возрастанию, остальные - в порядке добавления.

### Проверка на существование свойства

```js
const obj = {
  key: 1,
};

console.log("key" in obj); // true
console.log(obj.hasOwnProperty("key")); // true - только собственное
console.log(obj.key !== undefined); // true - но не работает, если значение undefined
```

> [!IMPORTANT]
> `in` проверяет и собственные, и унаследованные свойства.
> `hasOwnProperty` - только собственные.

### Перебор свойств

```js
const user = { name: "John", age: 20 };

// for...in - перебирает все перечисляемые свойства (включая унаследованные)
for (let key in user) {
  console.log(key); // "name", "age"
}

// Object.keys - только собственные ключи
Object.keys(user).forEach((key) => console.log(key));

// Object.values - только значения
Object.values(user).forEach((value) => console.log(value));

// Object.entries - пары [ключ, значение]
Object.entries(user).forEach(([key, value]) => console.log(key, value));
```

## Ссылки и копирование объектов

Переменная, которой присвоен объект, хранит его адрес в памяти (ссылку), а не делает копию объекта.

```js
const obj = {
  name: "John",
};

const obj2 = obj;
obj2.name = "Bob";

console.log(obj); // Bob
```

Две переменные равны только в том случае, если они ссылаются на один и тот же объект.

```js
const obj1 = {};
const obj2 = {};
const obj3 = obj1;

console.log(obj1 == obj2, obj1 === obj2); // false, false
console.log(obj1 == obj3, obj1 === obj3); // true, true
```

Поверхностное копирование объекта достигается тремя способами:

- Через spread оператор: `clone = {...user}`
- Копированием элементов объекта в цикле в новый объект.
- Через метод объектов: `Object.assign(dest, [src1, src2, src3...])`

```js
const user = { name: "John", age: 20 };

// 1. Spread
const clone1 = { ...user };

// 2. Цикл
const clone3 = {};
for (let key in user) {
  clone3[key] = user[key];
}

// 3. Object.assign
const clone2 = Object.assign({}, user);
```

Вложенное копирование делается двумя способами:

- С помощью функций: `_.cloneDeep(obj)` (в библиотеке loadsh) и `structuredClone()` (встроенный метод, поддерживаемый современными браузерами)
- Рекурсивно

```js
// 1. structuredClone (встроенный, современные браузеры)
const deepClone = structuredClone(user);

// 2. Lodash
const deepClone = _.cloneDeep(user);

// 3. Рекурсивно
function deepClone(obj) {
  if (obj === null || typeof obj !== "object") return obj;
  const clone = Array.isArray(obj) ? [] : {};
  for (let key in obj) {
    clone[key] = deepClone(obj[key]);
  }
  return clone;
}
```

## Сборка мусора

Объект помечается мусором, когда становится недостижимым (у него отсутствуют входящие ссылки).
Работа сборщика мусора происходит автоматически, мы не можем ускорить ее или отменить.

> [!NOTE]
> Сборщик мусора использует алгоритм mark-and-sweep:
>
> 1. Находит все "корневые" объекты (глобальные переменные, стек вызовов)
> 2. Помечает все достижимые объекты
> 3. Удаляет недостижимые

## Методы объекта

В объект можно добавлять любые методы, что позволяет реализовывать принцип ООП.

```js
const user = {
  name: "John",

  sayHi() {
    // 1-й вариант задания метода
    console.log(`Hello, I'm ${this.name}`);
  },

  sayHello: function () {
    // 2-й вариант
    console.log("Hello!");
  },
};
```

Ключевое слово `this` используется для доступа к элементам внутри объекта.
Оно определяется в момент вызова, а не объявления:

```js
const user = {
  name: "John",
  sayHi() {
    console.log(this.name);
  },
};

const fn = user.sayHi;
fn(); // undefined - this потерян
user.sayHi(); // "John" - this = user

const admin = { name: "Admin" };
admin.sayHi = user.sayHi;
admin.sayHi(); // "Admin" - this = admin
```

## Функция-конструктор

- Имя начинается с заглавной буквы
- Обязательно должна вызываться через `new`

```js
function User(name, age) {
  this.name = name;
  this.age = age;
}

let user = new User("John", 20);
console.log(user.name); // John
```

Если функция была вызвана при помощи `new`, то это можно проверить при помощи свойства `new.target`.
В случае обычного вызова получим значение undefined, а в случае вызова через `new` - саму функцию.

Если в функции-конструкторе присутствует `return`, то он может вернуть только объект, в ином случае значение проигнорируется.

```js
function BigUser() {
  this.name = "John";
  return { name: "Godzilla", age: 30 };
}

console.log(new BigUser()); // {name: 'Godzilla', age: 30}
```

## Опциональная цепочка

Опциональная цепочка `?.` - это безопасный способ доступа к свойствам вложенных объектов.
Она останавливает вычисление, если значение перед `?.` равно `null`/`undefined`.

```js
let user = {}; // пользователь без адреса
console.log(user?.address?.street); // undefined (без ошибки)
```

## Преобразования объектов

- Все объекты `true`, даже пустые.
- Численное преобразование происходит при вычитании и других математически операциях над объектами.
- Строковое преобразование объекта происходит, когда мы выполняем его вывод.
