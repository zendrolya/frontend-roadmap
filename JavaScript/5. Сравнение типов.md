# Сравнение типов

[⬅️Назад](./4.%20Преобразование%20типов.md) | [🏠Содержание](../README.md) | [Вперед➡️](./6.%20Логические%20операторы.md)

Любой результат сравнения возвращает `true` или `false`.

Таблица операторов сравнения:

| Оператор  | Название                | Приведение типов              |
| --------- | ----------------------- | ----------------------------- |
| ==        | нестрогое равенство     | да (кроме `null`/`undefined`) |
| !=        | нестрогое неравенство   | да                            |
| ===       | строгое равенство       | нет                           |
| !==       | строгое неравенство     | нет                           |
| > < >= <= | больше/меньше или равно | да (кроме строк)              |

## Сравнение строк

Строки сравниваются между собой в лексикографическом (алфавитном) порядке.

```js
console.log("Я" > "А"); // true
console.log("сон" < "сонный"); // true
```

Порядок символов алфавита равен порядку символов в таблице Unicode.

## Сравнение разных типов

При сравнении разных типов происходит попытка привести их к числу.

```js
console.log("2" > 1); // true, строка '2' становится числом 2
console.log("01" == 1); // true, строка '01' становится числом 1
```

Оператор `===` (строгое равенство) проверяет значения без приведения типов.

## Сравнение с `null` и `undefined`

При использовании `==` `null` и `undefined` **не преобразуются**, но считаются **равными друг другу** и ничему другому.

```js
console.log(undefined == null); // true
console.log(undefined === null); // false
console.log(null == 0); // false
```

При использовании операторов сравнения `null` преобразуется в `0`, а `undefined` в `NaN`, которое ничему не равно.

```js
console.log(null >= 0); // true
console.log(null > 0); // false
console.log(NaN == NaN); // false
console.log(undefined >= 0); // false
```

## Сравнение объектов

```js
{} == {}      // false
[] == []      // false
[] == ""      // true (пустой массив преобразуется в пустую строку)
[] == 0       // true
[1] == 1      // true
[1,2] == "1,2" // true (заполненный массив преобразуется в строку с перечисленными через запятую значениями)
```
