## Function Declaration (объявление функции)

```js
function name(attributes) {
  return;
}
```

## Function Expression (функциональное выражение)

**Function Expression** - функция, заданная переменной.

```js
let sum = function (a, b) {
  return a + b;
};
```

## Ключевое отличие Function Expression от Function Declaration

FE создается тогда, когда выполнение кода доходит до него, а FD может быть вызвана раньше, чем объявлена, так как движок заранее создает такую функцию.

```js
sayHi("Name"); // Привет, Name

function sayHi(name) {
  console.log(`Привет, ${name}`);
}

sayHi("Name"); // Cannot access 'sayHi' before initialization

let sayHi = function (name) {
  console.log(`Привет, ${name}`);
};
```

## IIFE (Immediately Invoked Function Expression)

Определяем анонимную функцию и сразу же ее вызываем.

```js
(function () {
  console.log("Привет мир");
})();
```

## Arrow Function (стрелочная функция)

```js
let sum = (a, b) => a + b;
console.log(sum(1, 2)); // 3
```

Главные отличия от обычных функций:

- Нет своего `this` - берётся из родительской области и не меняется.
- Нет `arguments` - но есть rest-параметры.
- Нельзя использовать с `new` - не может быть конструктором.
- Нет `prototype`.
- Нельзя использовать `yield` - не может быть генератором.
- Нет `super` и `new.target`.

## Callback Functions (функции-коллбэки)

**Функции-коллбэки** - это функции, которые мы передаём в другую функцию и вызываем в нужном месте.

```js
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

function showOk() {
  alert("Вы согласны.");
}

function showCancel() {
  alert("Вы отменили выполнение.");
}

// функции showOk, showCancel являются коллбэками, которые мы передаем в ask
ask("Вы согласны?", showOk, showCancel);
```

**Функции высшего порядка** - функции, которые могут принимать или создавать внутри себя функции.

## Замыкание

**Замыкание** - это функция, которая запоминает свою внешнюю область видимости даже после того, как внешняя функция завершилась.

```js
function makeCounter() {
  let count = 0;

  return function () {
    return ++count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```
