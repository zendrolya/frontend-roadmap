## HTTP-коды

Коды ошибок `status`:

| Диапазон  | Значение       | Примеры                                                                 |
| --------- | -------------- | ----------------------------------------------------------------------- |
| `100-199` | Информационные | `101 Switching Protocols`                                               |
| `200-299` | Успех          | `200 OK`, `201 Created`, `204 No Content`                               |
| `300-399` | Редиректы      | `301 Moved Permanently`, `304 Not Modified`                             |
| `400-499` | Ошибки клиента | `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found` |
| `500-599` | Ошибки сервера | `500 Internal Server Error`, `502 Bad Gateway`                          |

## Fetch API

```js
fetch("url", [options]); // возвращает промис
```

Пример простейшего запроса:

```js
fetch("https://jsonplaceholder.typicode.com/posts/1")
  .then((response) => {
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }
    return response.json();
  })
  .then(console.log)
  .catch(console.error);
```

> [!WARNING]
> `fetch` не отклоняется при HTTP-ошибках! Промис отклоняется только при сетевых ошибках (нет интернета, DNS, CORS).
> Поэтому необходимо проверять `response.ok` вручную.

### Свойства `response`

```js
response.ok; // true если status 200-299
response.status; // 200, 404, 500...
response.statusText; // "OK", "Not Found"
response.headers; // заголовки
response.url; // итоговый URL (после редиректов)
response.redirected; // был ли редирект
```

### Методы чтения тела

```js
response.text(); // текст
response.json(); // JSON => объект
response.formData(); // FormData
response.blob(); // Blob (бинарные данные)
response.arrayBuffer(); // ArrayBuffer (низкоуровневые бинарные)
```

> [!IMPORTANT]
> Тело можно прочитать только один раз. Повторный вызов `json()` или `text()` выбросит ошибку.

### Отправка cookies

```js
fetch(url); // credentials: "same-origin" (по умолчанию)
fetch(url, { credentials: "include" }); // отправлять cookies на другой домен
fetch(url, { credentials: "omit" }); // не отправлять
```

### Методы запроса (CRUD)

CRUD (create, read, update, delete)-операции в HTTP доступны следующим образом:

| Метод  | CRUD   | Описание           |
| ------ | ------ | ------------------ |
| GET    | Read   | Получить данные    |
| POST   | Create | Создать            |
| PUT    | Update | Полностью заменить |
| PATCH  | Update | Частично обновить  |
| DELETE | Delete | Удалить            |

```js
// POST
fetch("/api/users", {
  method: "POST",
  body: JSON.stringify({ name: "John" }),
  headers: {
    "Content-Type": "application/json",
  },
});

// PUT
fetch("/api/users/1", {
  method: "PUT",
  body: JSON.stringify({ id: 1, name: "John" }),
  headers: { "Content-Type": "application/json" },
});

// DELETE
fetch("/api/users/1", { method: "DELETE" });
```

## `FormData`

```js
const formData = new FormData();
formData.append("name", "John");
formData.append("file", fileInput.files[0]);

fetch("/api/upload", {
  method: "POST",
  body: formData,
  // Content-Type НЕ указываем - браузер сам установит multipart/form-data
});
```

## `AbortController` - отмена запросов

```js
const controller = new AbortController();

fetch(url, { signal: controller.signal })
  .then((response) => response.json())
  .catch((error) => {
    if (error.name === "AbortError") {
      console.log("Запрос отменен");
    }
  });

// Отмена
controller.abort();
```

## Таймаут для `fetch`

```js
async function fetchWithTimeout(url, timeout = 5000) {
  const controller = new AbortController();
  const id = setTimeout(() => controller.abort(), timeout);

  try {
    const response = await fetch(url, { signal: controller.signal });
    return response;
  } finally {
    clearTimeout(id);
  }
}
```

## XMLHttpRequest (legacy)

AJAX (асинхронный JS и XML) - подход к использованию существующих технологий вместе для обмена данными.

Legacy вариант работы:

```js
const xhr = new XMLHttpRequest();
xhr.open("GET", url);
xhr.responseType = "json";
xhr.send();

xhr.onload = () => {
  if (xhr.status === 200) {
    console.log(xhr.response);
  } else {
    console.error(`HTTP ${xhr.status}`);
  }
};

xhr.onerror = () => console.error("Ошибка сети");
xhr.onprogress = (event) => {
  console.log(`Загружено: ${event.loaded} из ${event.total}`);
};
```

## Версии HTTP

| Версия   | Особенности                            |
| -------- | -------------------------------------- |
| HTTP/1.1 | Один запрос на соединение (keep-alive) |

## CORS (Cross-Origin Resource Sharing)

**CORS** - механизм, позволяющий браузеру запрашивать ресурсы с другого домена.

По умолчанию браузер блокирует кросс-доменные запросы.

### Простой запрос

Условия:

1. Метод: `GET`, `POST`, `HEAD`
2. Заголовки: только `Accept`, `Accept-Language`, `Content-Language`, `Content-Type`
3. Content-Type: `text/plain`, `multipart/form-data`, `application/x-www-form-urlencoded`

## WebSocket

```js
const socket = new WebSocket("wss://example.com/socket");

socket.onopen = () => console.log("Открыто");
socket.onmessage = (event) => console.log(event.data);
socket.onerror = (error) => console.error(error);
socket.onclose = () => console.log("Закрыто");

socket.send(JSON.stringify({ type: "message", text: "Привет" }));
socket.close();
```
