# Символы

[⬅️Назад](./12.%20Контекст%20вызова%20функции.md) | [🏠Содержание](../README.md) | [Вперед➡️](./14.%20Методы%20чисел.md)

**Символ** - уникальный идентификатор, который **гарантированно не равен ничему другому**, даже если у двух символов одинаковое описание.

```js
const id1 = Symbol("id"); // создание символа "id"
const id2 = Symbol("id");
console.log(id1 === id2); // false - разные символы
```

## Преобразование символа в строку

```js
console.log(id.toString()); // "Symbol(id)"
console.log(id.description); // "id"
```

## Использование в объектах

Символы используются как "скрытые" свойства - снаружи нельзя получить к ним доступ без ссылки на сам символ.

```js
let user = {
  name: "Вася",
};

let id = Symbol("id");
user[id] = 1;

console.log(user[id]); // 1 - доступ по ссылке на символ
console.log(user["id"]); // undefined - строкового ключа "id" нет
```

Символьные свойства не видны для цикла `for...in`, а вот `Object.assign()` копирует все, в том числе и символьные свойства.

## Глобальный реестр символов

Существует глобальный реестр символов, из которого мы можем считывать символы (или создавать в случае отсутствия такого названия).

```js
Symbol.for(key);
```

Можно по символу определить его имя через метод:

```js
Symbol.keyFor(sym);
```
