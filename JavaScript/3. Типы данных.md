# Типы данных

[⬅️Назад](./2.%20use%20strict.md) | [🏠Содержание](../README.md) | [Вперед➡️](./)

В JavaScript существует **8 типов данных**:

- **7 примитивных:** `undefined`, `null`, `number`, `bigint`, `string`, `symbol`, `boolean`
- **1 объект:** `object` (включая массивы, функции, даты и т.д.)

## Примитивные типы

### `undefined`

`undefined` означает, что значение не было присвоено.

```js
let a; // объявили переменную a, но не назначили ей значение
console.log(a); // undefined
```

### `null`

Специальное значение, которое означает отсутствие значения/пустое значение.

```js
const myValue = null;
```

Зачем использовать `null`:

- Явное указание на отсутствие значения.
- Сброс значения в переменной.
- Ручное освобождение памяти.

### `number`

Представляет как целые, так и вещественные числа, а также специальные значения: `Infinity`, `-Infinity`, `NaN`.

`Infinity`/`-Infinity` получается при делении на `0`/`-0`, а `NaN` в результате вычислительной ошибки (когда `не число` или `NaN` взаимодействует в арифметических операциях с числом).

### `bigint`

`number` не может безопасно работать с числами больше `(2 ** 53 - 1)` или меньше `-(2 ** 53 - 1)`.

`bigint` используется для работы с целыми числами произвольной длины, которые не помещаются в `number`.

Создается путем указания `n` в конце числа:

```js
const bigInt = 1234567890123456789012345678901234567890n;
```

> [!WARNING]
> Нельзя смешивать `bigint` и `number` в арифметических операциях:
>
> ```js
> 1n + 1; // TypeError: Cannot mix BigInt and other types
>
> // Но можно сравнивать:
> 1n == 1; // true
> 1n === 1; // false (разные типы)
> ```

### `string`

Строковый тип.
Строки иммутабельны - их нельзя изменить после создания.

```js
const str = "Hello, world!";
```

### `symbol`

Уникальный идентификатор, который не равен ничему другому.

```js
const id1 = Symbol("id");
const id2 = Symbol("id");
console.log(id1 === id2); // false
```

### `boolean`

Может принимать только два значения: true/false.

```js
let isAlive = true;
```

## Объекты

Объект - сложный тип данных, который может хранить значения любых типов, включая другие объекты.

## Оператор `typeof`

Возвращает тип аргумента в виде строки:

```js
console.log(typeof 5); // "number"
```

> [!WARNING]
> `typeof null` возвращает `"object"` - это историческая ошибка JavaScript, которую нельзя исправить из-за обратной совместимости.
