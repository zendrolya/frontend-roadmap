# Работа с DOM

[⬅️Назад](./17.%20Регулярные%20выражения.md) | [🏠Содержание](../README.md) | [Вперед➡️](.//19.%20localStorage,%20sessionStorage,%20document.cookie,%20IndexedDB.md)

**DOM (Document Object Model)** - программный интерфейс для HTML/XML документов, представляющий их в виде дерева объектов.

## Получение элементов

```js
document.getElementById("id"); // по id
document.getElementsByClassName("class"); // по классу (живая коллекция)
document.getElementsByTagName("div"); // по тегу (живая коллекция)
document.querySelector(".class"); // по CSS-селектору (первый)
document.querySelectorAll(".class"); // по CSS-селектору (все)
```

> [!WARNING]
> `getElementsBy*` и `querySelector` возвращают живые коллекции (`HTMLCollection`), а `querySelectorAll` - статичные (NodeList).
>
> ```js
> const live = document.getElementsByClassName("item");
> const static = document.querySelectorAll(".item");
>
> document.body.appendChild(newItem);
> console.log(live.length); // увеличится
> console.log(static.length); // не изменится
> ```

## Свойства элементов

### Содержимое

```js
element.textContent; // весь текст (включая скрытый), быстрее
element.textContent = "..."; // безопасная замена текста

element.innerText; // только видимый текст, вызывает reflow
element.innerHTML; // HTML-содержимое, XSS-риск с пользовательскими данными

element.outerHTML; // HTML вместе с самим элементом
```

### Атрибуты

```js
element.getAttribute("href"); // получить
element.setAttribute("href", "..."); // установить
element.removeAttribute("href"); // удалить
element.hasAttribute("href"); // проверить

// Или как свойства
element.href; // получить
element.href = "..."; // установить
```

### Data-атрибуты

Пример:

```html
<div data-user-id="123" data-role="admin"></div>
```

```js
element.dataset.userId; // "123" (data-user-id => camelCase)
element.dataset.role; // "admin"
element.dataset.userId = "456"; // изменит data-user-id
delete element.dataset.role; // удаление
```

### Стили

```js
element.style.color = "red"; // инлайн-стиль
element.style.fontSize = "20px"; // camelCase

// Получить вычисленные стили
const styles = getComputedStyle(element);
console.log(styles.color); // "rgb(255, 0, 0)"
```

### Размеры и координаты

```js
element.getBoundingClientRect(); // {top, left, width, height, ...}

element.offsetWidth; // ширина с границами и padding
element.offsetHeight; // высота
element.clientWidth; // ширина без границ, с padding
element.scrollTop; // прокрутка
element.scrollHeight; // полная высота
element.scrollIntoView(); // прокрутить к элементу
```

## Классы элемента

```js
element.classList.add("active");
element.classList.remove("active");
element.classList.toggle("active");
element.classList.contains("active"); // true/false
element.classList.replace("old", "new");

element.className; // строка со всеми классами
element.className = "a b c"; // заменить все классы
```

## Навигация по DOM

```js
element.parentElement; // родитель
element.children; // дети (HTMLCollection)
element.firstElementChild; // первый ребёнок
element.lastElementChild; // последний ребёнок
element.nextElementSibling; // следующий сосед
element.previousElementSibling; // предыдущий сосед

element.closest(".container"); // ближайший родитель по селектору
element.matches(".active"); // соответствует ли селектору
parent.contains(child); // содержит ли элемент
```

## Создание и добавление элементов

```js
// Создание
const el = document.createElement("div");
el.className = "card";
el.textContent = "Привет";
el.setAttribute("data-id", "1");
el.style.color = "red";

// Добавление
container.append(el); // в конец
container.prepend(el); // в начало
parent.insertBefore(el, child); // перед child
oldElement.replaceWith(newEl); // замена
container.append("текст", el); // можно несколько узлов

// insertAdjacentHTML - HTML-разметка
element.insertAdjacentHTML("beforebegin", "<p>До</p>");
element.insertAdjacentHTML("afterbegin", "<p>В начале</p>");
element.insertAdjacentHTML("beforeend", "<p>В конце</p>");
element.insertAdjacentHTML("afterend", "<p>После</p>");
```

**Позиции `insertAdjacentHTML`:**

```html
<!-- beforebegin -->
<div>
  <!-- afterbegin -->
  Контент
  <!-- beforeend -->
</div>
<!-- afterend -->
```

## Клонирование элементов

```js
const clone = element.cloneNode(true); // глубокая копия
const shallow = element.cloneNode(false); // без детей
container.append(clone);
```

## Удаление элементов

```js
element.remove(); // удалить элемент
parent.removeChild(child); // старый способ
```

> [!NOTE]
> При удалении элемента его обработчики автоматически удаляются сборщиком мусора, если на элемент нет других ссылок. Вручную удалять их не нужно.

## События

### Способы навешивания

```js
// 1. Свойство (перезаписывается)
element.onclick = handler;

// 2. addEventListener (можно несколько)
element.addEventListener("click", handler);

// Снятие
element.removeEventListener("click", handler);
element.onclick = null;
```

**`addEventListener` поддерживает опции:**

```js
element.addEventListener("click", handler, { capture: true }); // фаза погружения
element.addEventListener("click", handler, { once: true }); // один раз
element.addEventListener("scroll", handler, { passive: true }); // оптимизация
```

### Объект события

```js
function handleEvent(event) {
  console.log(event.type); // "click"
  console.log(event.target); // элемент-инициатор
  console.log(event.currentTarget); // элемент с обработчиком
  console.log(event.clientX, event.clientY); // координаты
  console.log(event.key); // клавиша (для keydown)

  event.preventDefault(); // отменить стандартное поведение
  event.stopPropagation(); // отменить всплытие
}
```

- `event.target` - где произошло событие (инициатор).
- `event.currentTarget` - где навешан обработчик.
- `this` в не-стрелочном обработчике = `currentTarget`.

### Всплытие и погружение

Три фазы события:

1. Capturing (погружение) - от `window` к цели
2. Target - на самом элементе
3. Bubbling (всплытие) - от цели к `window`

```js
// По умолчанию - bubbling
element.addEventListener("click", handler);

// Capturing
element.addEventListener("click", handler, { capture: true });

// Остановить всплытие
event.stopPropagation();

// Проверить, всплывает ли событие
event.bubbles; // true/false
```

### Делегирование событий

```js
// Обработчик на каждом элементе
document.querySelectorAll(".item").forEach((item) => {
  item.addEventListener("click", handler);
});

// Один обработчик на родителе
document.querySelector(".list").addEventListener("click", (e) => {
  if (e.target.matches(".item")) {
    console.log("Клик по item:", e.target);
  }
});
```

Преимущества: работает для динамических элементов, экономит память.

### Работа с формами

```js
form.addEventListener("submit", (event) => {
  event.preventDefault(); // отменить отправку
  // ... логика
  form.reset(); // сброс полей
});
```

## MutationObserver

Отслеживание изменений в DOM:

```js
const observer = new MutationObserver((mutations) => {
  mutations.forEach((m) => console.log(m.type));
});

observer.observe(element, {
  childList: true, // добавление/удаление детей
  attributes: true, // изменение атрибутов
  subtree: true, // наблюдать за потомками
});

observer.disconnect(); // остановить
```
