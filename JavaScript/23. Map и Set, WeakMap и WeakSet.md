# Map и Set, WeakMap и WeakSet

## Map

**Map** - коллекция ключ/значение, как и `Object`. Главное отличие: ключом может быть любой тип (включая объекты).

### Методы и свойства

```js
const map = new Map();

map.set("key", "value"); // записать
map.get("key"); // "value" — получить
map.has("key"); // true — проверить наличие
map.delete("key"); // удалить
map.clear(); // очистить все
map.size; // количество элементов
```

### Ключи любого типа

```js
const map = new Map();

map.set("1", "строка");
map.set(1, "число");
map.set(true, "булево");

console.log(map.get(1)); // "число" - не путается со строкой "1"
console.log(map.get("1")); // "строка"
console.log(map.size); // 3
```

> [!IMPORTANT]
> В `Map` ключи не приводятся к строкам (в отличие от `Object`).

### Объекты как ключи

Это главная фишка `Map`. В `Object` объект-ключ превратился бы в `"[object Object]"`:

```js
// С Object не сработает
const visitsCountObj = {};
const john = { name: "John" };
const ben = { name: "Ben" };

visitsCountObj[john] = 1;
visitsCountObj[ben] = 2;
console.log(visitsCountObj); // { "[object Object]": 2 } — оба схлопнулись!

// С Map работает
const visitsCountMap = new Map();
visitsCountMap.set(john, 1);
visitsCountMap.set(ben, 2);
console.log(visitsCountMap.get(john)); // 1
console.log(visitsCountMap.get(ben)); // 2
```

### Сравнение ключей

`Map` использует алгоритм `SameValueZero` - почти как `===`, но `NaN` считается равным `NaN`:

```js
const map = new Map();
map.set(NaN, "значение");
console.log(map.get(NaN)); // "значение"
```

### Цепочка вызовов

`map.set()` возвращает сам объект `map`, поэтому вызовы можно объединять:

```js
map.set("1", "str1").set(1, "num1").set(true, "bool1");
```

### Перебор Map

```js
map.keys(); // итерируемый объект по ключам
map.values(); // по значениям
map.entries(); // по парам [ключ, значение] - по умолчанию в for...of
```

```js
const recipeMap = new Map([
  ["огурец", 500],
  ["помидор", 350],
  ["лук", 50],
]);

for (const [key, value] of recipeMap) {
  console.log(`${key}: ${value}`);
}

// Или через forEach
recipeMap.forEach((value, key, map) => {
  console.log(`${key}: ${value}`);
});
```

### Map из Object и обратно

```js
const obj = { name: "John", age: 30 };

// Object -> Map
const map = new Map(Object.entries(obj));
console.log(map.get("name")); // "John"

// Map -> Object
const backToObj = Object.fromEntries(map);
console.log(backToObj); // { name: "John", age: 30 }

// Или короче
const backToObj2 = Object.fromEntries(map); // .entries() не нужен
```

## Set

Set - коллекция уникальных значений (без ключей). Каждое значение появляется только один раз.

### Методы и свойства

```js
const set = new Set();

set.add("значение"); // добавить (если уже есть — ничего не произойдёт)
set.delete("значение"); // удалить, возвращает true/false
set.has("значение"); // true/false
set.clear(); // очистить
set.size; // количество элементов
```

### Уникальность

```js
const set = new Set();

set.add("John");
set.add("John");
set.add("Ben");

console.log(set); // Set(2) { "John", "Ben" }
```

> [!TIP]
> `Set` лучше оптимизирован для проверки уникальности, чем массив с `arr.find()`. Особенно для больших коллекций.

### Перебор Set

```js
const set = new Set(["a", "b", "c"]);

for (const value of set) {
  console.log(value);
}

set.forEach((value, valueAgain, set) => {
  console.log(value);
});
```

> [!NOTE]
> В `forEach` у `Set` три аргумента: `value`, `valueAgain` (то же самое), `set`. Это сделано для совместимости с `Map`.

### Методы совместимости с Map

```js
set.values(); // то же, что и сам Set
set.keys(); // синоним values() - для совместимости с Map
set.entries(); // пары [значение, значение] - для совместимости с Map
```

## WeakMap

WeakMap - коллекция ключ/значение, где:

- Ключи - только объекты
- Если на объект-ключ больше нет ссылок, он автоматически удаляется сборщиком мусора

### Пример проблемы с Map

```js
let john = { name: "John" };
const map = new Map();
map.set(john, "...");

john = null; // перезаписали ссылку

// Объект john всё ещё в памяти, потому что он ключ в Map
console.log(map.size); // 1
```

Решение с WeakMap:

```js
let john = { name: "John" };
const weakMap = new WeakMap();
weakMap.set(john, "...");

john = null; // Объект автоматически удалён из WeakMap
```

### Методы WeakMap

```js
weakMap.get(key);
weakMap.set(key, value);
weakMap.delete(key);
weakMap.has(key);
```

> [!WARNING]
> Нельзя перебирать `WeakMap` и использовать `size`, `keys()`, `values()`, `entries()`. Это связано с тем, что движок сам решает, когда удалить объекты.

## WeakSet

`WeakSet` - аналог `Set`, но:

- Только объекты (не примитивы)
- Объект хранится, пока на него есть ссылки
- Поддерживает `add`, `has`, `delete`
- Не поддерживает `size`, `keys()`, перебор

```js
const readMessages = new WeakSet();
readMessages.add(messageObj);
readMessages.has(messageObj); // true
```

## Когда что использовать

| Структура | Когда использовать                                           |
| --------- | ------------------------------------------------------------ |
| Object    | Простые данные, ключи-строки, JSON                           |
| Map       | Ключи любого типа, частые добавления/удаления, важен порядок |
| Set       | Уникальные значения, быстрая проверка наличия                |
| WeakMap   | Доп. данные для объектов (кеш, счётчики), без утечек         |
| WeakSet   | Флаги "да/нет" для объектов, без утечек                      |
